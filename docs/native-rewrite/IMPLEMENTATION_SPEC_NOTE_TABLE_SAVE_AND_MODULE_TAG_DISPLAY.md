# 错题笔记表格保存与模块标签展示

## 1. 保存含表格的错题笔记

- 入口为错题详情 → 错题笔记 → 粘贴或插入表格 →「完成」。截图显示原笔记状态和可渲染的恢复草稿。源码中，正式写入用整题的时间及载荷哈希校验；题目的其他字段变化也会产生版本冲突。截图没有日志，无法确定当次导致冲突的字段。表格继续使用现有结构化附件编码。
- 新开编辑使用当前题的实时保存基准。正式写入时若基准版本变化，先确认原始载荷哈希可验证、当前笔记正文与原始笔记相同，再在最新整题载荷上重做笔记写入；后台准备结束时再次核对版本。整个流程继续走原保存队列，保存回执使用实际落盘的版本及载荷。用户可见的笔记已有变化，或者旧草稿基准不可验证时，进入原有冲突处理。
- 写入失败时保留表格、正文和原记录。错误信息在笔记标题下方以 11 pt 次要字号、错误色、左对齐换行。无冲突的恢复草稿顶部提供「保存草稿」快捷操作，行内蓝色 13 pt 半粗，触控高度 44 pt；复用已有原文写入、回执检查和恢复版本保护。
- 验收：普通笔记、从剪贴板粘贴的横线表格、正文内插入的新表格分别保存后重开。编辑期间只更新题目的非笔记属性后点完成，应保留新属性和整份笔记。原笔记被另一编辑修改时保留两份。核对活跃单元格的中文输入、已恢复草稿、真实失败信息和重试。

## 2. 标签展示按模块

- 标签管理的「标签展示」显示「科目 · 模块」。同模块的题型以及未分类共享四个原有开关；其他模块独立。数量关系现有扁平模块名称继续跟随改名和删除。
- 题型目录、实际标签和迁移规则保持原有数据。旧展示设置优先采用已保存的模块值。未设模块值时，若已配置的题型值一致则继承；有冲突时使用应用默认值，保存模块设置后以本次模块值为准。
- 题库卡片、错题详情和新增／编辑表单统一从同一模块范围读取设置。验收时在逻辑填空任选一题型设置，检查同模块另一题型、未分类及其他模块。

## 3. 卡片顶部的考点和错因标签

- 两类显示使用同一个样式组件，保留 11 pt 中等字重、5 pt 圆角和 0.75 pt 描边，随现有布局换行。考点在前，用应用强调蓝的文字和蓝色边框；错因标签继续用深色文字及浅灰边框。文字与背景保持现有间距。
- 保留每枚标签的类别，允许跨类别同名分别显示，类别内去重。只显示单类时继续使用该类别的样式，并保留顶部开关。验收组合开启、仅启用一类、同名标签以及窄分屏。
