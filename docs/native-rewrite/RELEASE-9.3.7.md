# 9.3.7 / Build 30 — 网页版速算反馈对齐

- 正确闪光移入练习内容背景：青绿色 #10B981、18%→0、280ms，不再叠在数字、题干和键盘之上；错误不触发背景闪光。
- 正误小提示使用网页成功绿 #34C759、浅色错误红 #FF3B30 / 深色 #FF453A、12pt medium 白字。300ms 向下淡入，2s 开始向上淡出，2.5s 移除；提示不拦截触摸，不等待提示结束再换题。
- 答案数字及下划线整体使用网页 150ms ease-out：scale 0.8→1、opacity 0.4→1。文字和 Core Animation 在同一次更新提交，固定动画键替换上一段，不使用延迟任务或动画队列。
- 左侧算式按题目 ID 播放 320ms、下方 10pt→原位淡入；等号和整行容器不参与缩放或移动。输入只让整行按实际答案宽度重新居中。
- 保留手动确认立即换题、单次按键事件、C 删一位/图标清空、无胶囊开始按钮及全宽点击区域。支持减少动态效果。
- 发布前运行源码契约、Swift 规则/布局测试与 iPad 模拟器点击测试，并增加快速双击计数验证。实际逐帧观感仍需真机与网页版对比。
