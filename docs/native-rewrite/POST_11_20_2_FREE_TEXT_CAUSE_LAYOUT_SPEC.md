# 自由文本错因逐条显示

## 入口与现状

适用于错题卡片和题目详情中的资料分析、言语理解／逻辑填空、数量关系「错因说明」自由文本。旧数据可能把错因存成单个字符串、字符串数组，或数量关系的兼容字段 `errorCause`、`cause`、`reason`。卡片和详情需要把换行项逐条显示，避免一串内容挤在同一横向标签流里。

## 目标与实现

- 只调整以上自由文本错因的展示与卡片高度估算。每个非空换行项单独占一行，顺序不变；自动折行只增加该项的行高，不把它拆成多个错因项。去掉空白行并裁剪每项首尾空白。逗号属于文本内容，不能据此拆项。
- 卡片沿用既有错因标签、字体、颜色、边距和卡片宽度。标签名留在左侧，错因项在右侧纵向排列，项间距 5 pt；长项在卡片可用宽度内折行。高度估算按错因项数量和每项预计折行数累加，保持瀑布流不会按横向标签流少估高度。
- 详情沿用现有可点编辑行，标签文字为「错因说明：」，错因项逐条竖排、保持现有字重和淡色背景。长项在详情可用宽度内折行。编辑后仍通过原有字段保存路径写入。
- 读写兼容：资料分析、逻辑填空继续兼容 `errorCause`、`cause`、`reason` 的字符串或数组；详情编辑保留已存在字段名和字符串／数组表示，统一按换行读写。数量关系沿用专用兼容读取和写入逻辑及权威字段规则；旧错因文本中的「、」仍可作为兼容分隔符，中文逗号和英文逗号保留为原句标点，旧 `weaknessTags` 标签仍按兼容分隔符处理。不得改变考点、错因标签、辨析、误区或提醒等非自由文本字段的展示和拆分。

## 验收

1. 在上述三个范围分别准备两条短错因，卡片和详情均显示为两行。
2. 准备一条包含中文逗号的长句并跨越多个视觉行，再跟一条短错因；长句仍作为同一错因项折行，第二项开始于独立下一行。
3. 保存带空白行和首尾空格的两项错因后关闭详情、重开并再次编辑；空白行不显示，顺序及文本内容保持。
4. 读取旧字符串、数组和数量关系兼容字段，编辑保存后重开；逐条显示仍正确，非错因标签字段未受影响。
5. 使用同批次必要行为检查、归档发布并核对 IPA 资产；不以源码检查代替真机布局验收。
