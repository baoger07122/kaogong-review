# 错题卡片顶部标签图标

- 入口为行测 → 错题 → 卡片模式。原卡片标签区共用一个深色灯泡，只有错因标签时也会显示。
- 考点保留原 `lightbulb.min`，11 pt、light 字重、11 pt 图标宽度及 6 pt 间隔。改用考点标签相同的应用强调蓝。标签区有考点时在首个考点旁显示一次，只有错因时不占用灯泡宽度。卡片高度估算按同样的规则决定是否扣除预留宽度。考虑窄分屏，文本按现有规则换行。
- 错因图标先在同尺寸的卡片预览中比较。候选为放大镜、圈内感叹号、折角笔记、空心旗标。统一深灰细线及圆角收笔，选定后再接入 App。
- 验收：同时选中两类、只选考点、只选错因以及两类关闭。在窄分屏检查长标签，以及卡片标签颜色、图标对齐和读屏标签。

## 交付检查

- 蓝色灯泡与卡片高度估算已按考点存在状态同步。Swift 源码语法树无新增解析问题，差异检查通过。iPad 卡片和窄分屏仍待验证。
- 四款已用同一卡片渲染并检查，预览为 `card-mistake-icon-options.png`。

## 确认采用 C · 路径纠偏

- 采用第二版 `card-mistake-icon-details.png` 中的 C。错因标签在本组首项前使用深灰细线图标，绘制起点、分岔、箭头和错项叉号。图标为 11 × 11 pt、0.75 pt 线宽、圆角收笔，与考点蓝色灯泡共用 11 pt 图标位和 6 pt 间隔。
- 在卡片顶部按现有顺序分为考点和错因两组。两组的标签起点一致，间距沿用现有 4 pt。长标签换行后图标仍对齐首行。图标对读屏隐藏，标签继续朗读类别与名称。卡片高度估算使用同样的图标预留空间。
- 验收在同一卡片切换两类标签、一类和空标签，核对图标仅出现于相应组、长标签换行、卡片列高与之前蓝字蓝边框样式。

C 已接入卡片及其列高估算。差异检查通过，Swift 语法树无新增解析问题。iOS 编译、iPad 实际显示及读屏待验证。
