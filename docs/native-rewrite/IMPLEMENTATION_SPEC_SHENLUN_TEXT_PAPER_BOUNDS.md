- 入口为申论 → 单题或套卷练习 → 文字材料、「作答要求」。11.24.2 已包含作答输入及系统返回键、录入页「整理排版」和撤销；本图的问题发生在阅读页。发布源码用 TextKit 1 在固定宽度内分页，但正文由 SwiftUI 包装的默认 UITextView 单独布局、根据容器协商尺寸。截图可确认正文横跨纸面和窗口，具体 iPadOS 排版回调仍待运行时复核。
