## 本次执行范围

2026-11-20 已授权交由 Luna 实现并发布。执行第一节和第三节。选标签弹窗同时落实[已确认的输入框原型和验收规则](KNOWLEDGE_POINT_SELECTED_LABELS_SPEC.md)，覆盖考点和新增的错因标签入口。

## 一、统一题型管理

### 入口和现状

在「设置」新增独立的「题型管理」入口。当前数量关系使用单独入口，资料分析和言语理解从各自入口按模块管理。判断推理和常识判断已有模块，但目前缺少可维护的题型目录和对应的录入选择。

### 界面与操作

- 「设置 → 题型管理」按行测科目顺序列出言语理解、数量关系、判断推理、资料分析、常识判断。统一入口承接设置中原来的三条管理入口。科目与模块名从 `SubjectDefinition` 取值。
- 数量关系点入即显示题型列表。其余四科先显示各自的模块，再打开该模块的题型列表。言语理解和资料分析已有的跨模块通用分类继续可以在对应科目内管理。
- 题型列表统一使用「新增」「重命名」「排序」「删除」操作。沿用设置的原生列表、科目图标、强调色和次级导航。科目及模块行使用 14 pt 常规字重、至少 44 pt 高的点击区、左对齐和右侧进入箭头。列表空态显示「暂无题型」及「新增」入口。题型名称允许换行，窄窗管理操作可收进每行菜单。
- 行测错题的新增和编辑按「科目 → 模块 → 题型」选择。数量关系直接选择题型。列表在对应范围可按题型筛选，题目详情在原有元数据区显示题型名称。每题允许「未分类」。选择和管理面向同一目录，目录变更后刷新这些入口。
- 资料分析在管理页面统一称「题型」，已有的具体名称原样显示，例如「知识点错误」。

### 数据与实现

1. 在 `SettingsView`、`SettingsRoute` 增加管理页导航。复用 `QuantityQuestionTypeManagerView` 和 `LibraryErrorTypeModulesView`／`LibraryErrorTypeManagerView` 的目录维护行为，将指向旧入口的空态文案改为「设置 → 题型管理」。
2. 由 `QuantityQuestionTypeRepository` 继续解析数量关系的既有题型以及历史 `module` 记录。言语和资料保留 `verbal_reasoning_error_types`、`data_analysis_error_types` 和原有 ID。判断推理和常识判断分别使用按科目隔离的新增目录，目录项沿用稳定 ID、模块、显示名、列表顺序。两科的新分类关联使用错题已有的可选 `errorTypeID` 字段。旧题缺少关联时显示为未分类，题干、原有模块、标签、笔记和题库关联仍由原字段承载。
3. 检查 `LibraryRecordEditorView`、`LibraryRecordRepository`、`LibraryView` 和 `LibraryRecordDetailView` 的选择、保存、筛选与显示。一并核对判断推理专用的图形规律、识别思路等入口。切换科目或模块时仅保留仍在新范围有效的题型。对于 11.19.1 已有记录，使用其已保存分类和值，解析失败时按未分类呈现。单独浏览题库时继续使用题库自己的分类。
4. 新增／重命名去除首尾空白，同一管理范围同名或「未分类」提示冲突。重命名与排序保留已有引用。删除前显示影响范围，复用已有科目的确认与处理逻辑。新增两科移除目录项后，相关错题显示为未分类且保留题目和标签内容。数量关系改名时，迁移对应考点目录、分组、错因标签目录及错题引用到新题型；删除时迁移错因标签目录、分组及错题引用到未分类，现有数量关系考点仍按原有删除规则移除。写入失败时显示错误，目录和已关联错题保持在最后一次成功保存的状态。

### 验收

1. 从设置进入「题型管理」，检查五科顺序、数量关系直达列表、其余科目模块列表、资料分析已有错误类型的原名。
2. 在「判断推理 → 图形推理」及「常识判断 → 法律」各建一个题型。分别新增错题选中题型并保存。回列表用题型筛选，在详情确认显示名称，再打开编辑确认选中值。
3. 在两科分别重命名、调整顺序、删除一项。核对重命名后的题目、同名不同模块数据、删除后的未分类题目和标签。切换科目或模块验证失效的题型不会带入新范围。
4. 打开曾分类的言语理解、数量关系、资料分析错题及已有考点分组，核对原目录、题目与考点的对应关系。改名和删除数量关系题型后，检查考点与错因标签的既定迁移规则及已有错题引用。检查旧无分类题、重名校验、窄窗口长名称和分类保存失败。

## 二、按分类设置卡片标签

卡片页以现有版本为准。本节留作后续讨论。

### 现状

错题列表卡片顶部的 `questionKnowledgeHeader` 读取考点。「中心理解」在 `SubjectDefinition` 中是言语理解下的模块，模块内还可以建立具体题型。

### 设置入口与行为

- 入口为「设置 → 题型管理 → 言语理解 → 中心理解 → 标签展示」。在模块的题型列表上方放「标签展示」区。若只想改变该模块内某个题型，在该题型的设置中选择「跟随模块」或「自定义」。数量关系在题型列表提供科目默认值，各题型可选择跟随科目或自定义。
- 「卡片顶部」单选「考点」或「错因标签」。加原生开关「隐藏另一类标签」。打开后，在该分类的新增／编辑错题和详情中隐藏未选中的标签行。关闭后，两类标签行都可录入和查看，卡片顶部仍按单选设置。切换哪类置顶后，隐藏开关随新选择指向另一类。「错因说明」文字输入一直可用。
- 复用设置列表、系统勾选与开关样式。行标题 14 pt 常规字重、至少 44 pt 点击高度、左对齐，窄窗说明自然折行。题型页显示其当前实际设置，继承时显示「跟随模块」或「跟随科目」。
- 默认顶部显示考点标签，隐藏开关默认关闭。未分类的题使用所属模块设置，数量关系用科目默认值。模块内具体题型的自定义优先于模块。切换模块默认值时，继承此设置及未分类的题同步变化。

### 保存与列表显示

- 展示配置从题型管理保存到对应科目、模块或题型范围。题型配置随稳定 ID 解析。数量关系沿用旧名称关联的题型改名入口，同步更新配置键。配置保存失败时显示错误，列表仍读上次保存成功的配置。隐藏时保留已有引用，再次显示时恢复原值。
- 在 `LibraryComponents.swift` 中按每条记录所属科目、模块和已保存题型解析生效配置。混合列表的卡片各按自己的分类取值。顶部读取选定的标签引用，复用现有左对齐、换行标签流，约 11 pt medium、标签间距约 5 pt。顶部所选类型没有已选标签时省去该行。「错因说明」在题干后的信息区展示。数量关系独立的题型行按原有规则展示。
- 将已解析的标签设置随列表卡片输入传入，实际布局与预估高度使用同一标签集合。标签设置更新时刷新受影响范围的卡片。详情和编辑解析相同的有效可见性，沿用刷题时已有的信息展示边界。

### 验收

1. 在中心理解给两题分别录入考点、错因标签和错因说明。将模块的卡片顶部从「考点」切到「错因标签」。核对两题统一按所选类型显示，逻辑填空的卡片使用自己的设置。检查某题的所选标签为空时顶部省去标签行。
2. 为中心理解的一个具体题型设自定义，同时保留另一题型继承模块。切换模块设置，核对各自的卡片、未分类题、混合列表和窄窗长标签。改名、排序、退出重开后检查配置仍生效。
3. 打开「隐藏另一类标签」。在已有另一类标签的错题中修改文字错因并保存，检查录入和详情隐去对应标签行。关掉隐藏开关后，核对该题原有标签及新写入的文字说明均可查看。

## 三、标签管理与错因标签

### 入口与显示

- 首页原「考点管理」快捷入口及页标题统一叫「标签管理」。主页面使用「考点」「错因标签」两个分段，按「科目 → 模块 → 题型」管理。两类标签各有独立的集合、分组和排序。原有错因候选管理以「错因说明词库」从该页「…」进入，同菜单提供「思维误区」管理。
- 新增和编辑错题中，标签行依次为「考点」「错因标签」，下方的原文字输入标为「错因说明」。错因标签行复用考点的选择样式、文字、命中区和窄窗换行。点击两行分别打开「选择考点」「选择错因标签」，使用对应分类的候选。已选标签在灰框显示全名，可换行并逐项移除。
- 错题列表的「题库设置 → 显示控件」提供「标签筛选」。列表筛选入口可分别打开考点、错因标签选择器；错因标签候选按完整模块／题型引用区分同名标签。单类多选为任一匹配；考点与错因标签同时启用时，题目须同时匹配两类。取消不应用本次弹窗更改，「清除筛选」清空两类选择；题型或模块切换时移除新范围无效的引用。
- 两页都提供考点标签已有的搜选、多选、新增、无分组标签、建组和组内排序、移动分组、调整题型、重命名、删除与长按操作。跨题型选用沿用考点选择器的规则。两个页签各自加载当前类别的分组、候选和已选状态。

### 实现与数据

1. 在 `HomeComponents`、`HomeShortcutViews` 和 `KnowledgePointManagerView` 更新入口与分段。管理页、分组和选择器复用现有考点逻辑，用标签类别指定数据源。为题型化标签目录及分组增加类别隔离，同时区分科目、模块和题型。历史考点组在读取时默认归考点类别。现有 `VerbalReasoningKnowledgePointRepository.recordID(for:)` 的默认键会落到言语理解，为判断推理和常识判断分别分配明确的目录键。
2. 在 `LibraryRecordDraft`、草稿和错题载荷新增可选的独立引用数组 `mistakeTagRefs`，使用与已有考点相同的作用域及名称结构。旧记录字段缺失时读为空。旧考点引用和现有 `errorCause`／旧别名及其文字、数组兼容路径照常读写。新增数组走现有备份、同步和草稿恢复路径。
3. 弹窗「确定」更新相应标签草稿，整题「保存」持久化。标签库内重命名、删除和调整归属只修改同类且匹配来源的引用。跨类型重名、带逗号的名称按完整引用处理。隐藏录入行时继续保存该草稿已持有的数据。设置写入和题目编辑按各自保存边界处理。
4. 列表筛选只读取对应的 `knowledgePointRefs` 或 `mistakeTagRefs`。引用匹配包含模块和题型，不能仅按显示名称匹配；两类筛选条件同时启用时取交集，单类内部多选取并集。筛选状态按题目来源保留，作用域改变后裁去失效项。

### 验收

1. 在中心理解分别建立考点标签「主旨判断」和错因标签「把例子当主旨」。对错因标签完成不分组新增、建组、移动、排序、长按重命名和删除验证，同名考点检查独立。
2. 同一题选考点和多项错因标签，并在「错因说明」输入一段文字。点移除叉、取消、确定和整题保存，分别核对弹窗、编辑行和详情。重新打开及从草稿恢复时检查三个字段。
3. 在两个模块或题型创建同名且带「，」的错因标签，验证完整显示、只改对应来源和跨题型选择后仍保留身份。用旧无新字段的错题验证题目、原有标签和文字错因可查看。
4. 在错题列表分别按错因标签筛选、按考点与错因标签同时筛选，验证同名不同题型只命中所选引用；取消弹窗不改变结果，清除筛选恢复题目，切换模块或题型后失效选项被清理。
