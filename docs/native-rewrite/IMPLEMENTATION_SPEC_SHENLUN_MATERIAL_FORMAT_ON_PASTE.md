# 申论文字材料粘贴时整理断行

- 入口为申论单题或套卷录入、已有题目的文字材料编辑框。11.24.2 中长按粘贴仍把原文直接放到输入框，之前的「整理排版」只在主动点击时运行。截图中的词中断行、独立引号和上个句子的结尾需在粘贴时处理。
- 文字材料编辑框接入 UIKit 的系统粘贴回调，只整理本次粘贴的片段，按当前选区插入。套卷的批量粘贴在材料拆分、确认加入后逐份整理。原有材料可继续用输入框下方「整理排版」。纯文本里可识别的段落留一空行，保留标题、标点和有意段首。本次仅修改文字材料。
- 沿用材料框 15 pt 字号、至少 140 pt 高、既有白底细线及窄窗口布局。整理后在同位置显示「撤销整理」，恢复本次粘贴在该位置的原始断行，保留选区外原有文字；手工再编辑结束本次恢复状态。排版变更沿用材料版本记录，粘贴、整理和撤销在表单内暂存，保存题目后才写入。题干、作答要求、PDF／图片原页及手动输入按现有路径处理。
- 验收：复制带半个词、独立开闭引号和真实段落的材料至空框、段中光标、替换选区及批量材料。检查「极其简／单」等连回原词，段首及已存在的上下文保留。点击「撤销整理」核对原断行，重做保存并重新打开。按回车、输入中文或粘贴无断行内容时核对普通编辑行为。
