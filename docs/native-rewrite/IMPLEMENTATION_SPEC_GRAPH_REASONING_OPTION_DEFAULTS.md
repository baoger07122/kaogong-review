# 新增图形推理错题的默认选项

**入口与现状。** 行测 → 判断推理 → 图形推理 → 新增错题 →「题目与选项」。从其他行测入口新增错题后选到图形推理也适用。当前四行只有左侧的 A、B、C、D 行号，右侧输入框的值为空。

**目标与样式。** 沿用截图中的四行选项和原有 `LibraryErrorOptionEditorRow`。从上往下，右侧四个文本框实际写入 `A`、`B`、`C`、`D`，使用原有 13.5 pt 常规正文、左对齐、白底及输入框间距，窄窗口继续沿用原来的自适应布局。填入的文字可选中、修改或清空。正确选项和我的选项仍由用户选择。

**实现与边界。** 由新建错题编辑会话在首次进入图形推理时检查选项。直接新建图推在首次渲染前初始化。其他新增入口切入图推时，选项文字和选项图片都为空才填入。每个新建会话最多执行一次，之后按输入框实际值处理，清空后切回图推时不重复填入。已有题目和恢复的草稿优先使用原数据。正常输入、智能拆分及切换科目后可继续编辑当前选项。保存沿用 `LibraryRecordDraft.options` 到记录 `options` 的映射及原有保存失败处理，保留用户最终输入。

**验收。**

1. 直接新增图推错题，确认四个可编辑输入框各显示一个字母，答案选择器仍为空。
2. 将 B 改为其他文字，清空 D，切换模块再切回。确认文字和空值都保留，保存后重新打开核对。
3. 从其他科目新增，检查输入框为空。以空选项切入图推时预填。任一选项已有文字或图片时保留当前选项。
4. 重新打开已有图推错题或恢复草稿，核对原文字和空选项。
