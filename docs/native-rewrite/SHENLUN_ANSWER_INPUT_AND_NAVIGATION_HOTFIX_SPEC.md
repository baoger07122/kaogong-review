# 申论答题纸输入与返回热修规格

## 1. 练习详情的答题纸无法键入

- 入口：申论 → 单题练习或套卷练习 → 未完成题目的「答题纸」。
- 现状：点格纸只修改编辑状态。编辑器在格纸后方，长题需要滚到底才能看到，且没有主动申请输入焦点。无字数上限题的「键入」同样没有申请焦点。
- 目标：点红格或「键入」，在右栏顶部显示同一个原生多行编辑器并放置光标。输入时下方红格同步显示已确认的文本。点「收起」关闭编辑器并回到格纸。无字数上限的题收起后显示现有作答或可点击的空白提示。
- 实现：在 `ShenlunPracticeDetailView` 复用 `ShenlunCommittedTextEditor`。保持正文系统字号 15 pt、白底和 10 pt 内边距。编辑器最小高度沿用有上限 180 pt、无上限 220 pt，卡片圆角 12 pt。编辑器进入窗口后一次性申请焦点，已有答案从末尾继续，支持光标选择、中文候选和粘贴。保持左右分栏及窄窗口单列，键入时把对应答题区滚到可见位置。
- 状态与边界：编辑器和格纸共用当前题的 `answerText`。保留现有题 ID、计数、分张、超限提示和保存规则。只将已确认的输入写入草稿。离开练习详情时补存尚在防抖等待中的已确认作答。保留已完成作答的修订流程和现有保存失败提示。
- 验收：在 400 格题、跨两张纸的题和无字数上限题，分别从「键入」和答题区域点击进入输入。在 iPad 输入中文并提交候选，移动光标修改、粘贴长文本，核对格纸及计数。收起再展开，切换套卷题目，输入后立即返回并重新进入，确认草稿归属和内容。窄窗口下点红格，确认键盘出现时编辑器可见。

## 2. 练习详情返回键与 iPad 窗口按钮重叠

- 入口：从申论单题或套卷列表进入练习详情，在 iPad 分屏或窗口模式检查左上角。
- 现状：页面隐藏系统导航栏，在内容区自绘左上返回按钮，系统三个点也占用同一区域。
- 目标及实现：采用行测错题详情的系统导航栏，开启 `.toolbar(.visible, for: .navigationBar)` 和行内标题，由导航栈提供返回和侧滑。长标题单行省略。沿用 `.documentToolbarBackground()`，更多、图层、涂鸦保留在右侧。宽度小于 580 pt 时，绘画工具排在导航栏下一行靠右，沿用现有涂鸦工具与按压反馈；图层弹出框仍从图层入口打开。
- 验收：在 iPad 全屏、窄分屏和窗口模式分别推入同一详情，检查左上返回和系统三个点各自可点，核对系统侧滑、长标题、更多、图层和涂鸦在正常及紧凑宽度均可使用。

本次范围是练习详情的键入与返回交互。首页、录入页和疑惑区的排版设计作为独立事项。

## 交付记录

- 键入：格纸和「键入」共用同一焦点请求。原生编辑器位于预览上方。继续编辑使用此前保存的作答，预览、题号归属和超限处理沿用现有数据流。源代码检查通过。
- 返回：移除自绘返回按钮，确认练习详情由现有 `NavigationStack` 推入，并与行测详情一致启用系统导航栏。源代码检查通过。
- 检查：Swift 源码语法解析无错误，`git diff --check` 通过。当前 Windows 工作区无法运行 iOS 编译和交互验证。待在 iPad 核验光标、中文输入法、手滑返回、三个点的触控区域以及窄窗口涂鸦工具。
