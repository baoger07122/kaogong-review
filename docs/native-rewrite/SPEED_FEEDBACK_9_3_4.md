# 9.3.4 / Build 27 — 手动确认、反馈和结果页

## 本轮确认

用户明确不采用网页的自动确认：无论历史 `confirmAuto` 值是什么，均需点击 ✓ 提交。旧字段仅保留用于备份兼容，不再提供开关。

## 实现

- 按键按下立即加深、缩小，松手 70ms 恢复，不再使用回弹曲线。数字键 24pt medium（网页最终样式 500）。主页及键盘外围纯白；按键本身保留浅灰。
- 首位及后续输入均触发 90ms 数字反馈。用可取消任务重启单次动画，防止旧重置任务覆盖新输入；启用系统减少动态效果时不做位移和缩放。
- 手动提交显示 ✓/✗，答对淡绿闪光 280ms，题号反馈 200ms；220ms 后进入下一题，算式从下方 10pt 淡入 320ms。输入无效时提示，不跳题。
- 提交立即锁定本题，用题目 ID 校验及可取消任务阻止重复跳题；重开、退出会取消待处理任务。取消退出/重开提示不修改题目、输入或计时。
- 结果页使用六列表格、逐列字号和颜色、答案 ✓/✗ 及误差红绿区分，底部固定重来/复练/返回。窄窗口允许表格横向查看，避免压扁数字。
- “复练”只保留错题原题，清空答案和计时；全对时提示无需复练。完成时固定总用时并保存结果，复练不篡改原历史记录。
- 做题页草稿按钮和结果页右上角涂鸦入口复用现有 PencilKit 叠层，顶部提供退出、橡皮擦、撤销、清空、画笔调节。不会弹出新的半屏画布。

## 验证

本地运行 8 项错题页面源码约束及 6 项速算源码约束。CI 编译执行几何、输入/音频、手动提交/错题复练 Swift 测试，再执行 Xcode Release archive。
