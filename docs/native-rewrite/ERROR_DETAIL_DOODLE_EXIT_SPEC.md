# 错题涂鸦退出等待整改

- 入口为错题详情的普通涂鸦和资料分析分栏涂鸦，点现有工具栏「退出涂鸦」。工具栏的图标、尺寸、标准点击反馈和当前画布位置沿用原样。退出请求受理后立即撤下工具栏与触控遮罩，恢复题目纵向滚动。保留当前画布宿主直到最后一笔完成序列化；这段期间仍限制可能切换画布的导航。保存结束前仅暂停再次打开涂鸦。分栏保留原只读预览和材料／题目对应关系。
- 普通错题把 PencilKit 笔迹和兼容预览合到一次持久化。预览在后台生成，现有 `pencilKitData`、`drawingPreview`、`doodle` 字段兼容。无修改退出不生成预览也不写入。擦除全部笔迹沿用删除旧预览字段的处理。分栏继续只更新有变化的布局与画布，不为分栏生成普通涂鸦预览。旧版申论沿用现有保存行为。
- 持久化时对比准备前后的完整记录数据。若题目另有写入，基于最新数据重试。写入成功且详情仍在同一题、当前快照正是写入前版本时，直接接纳新画稿对应的完整已保存数据与记录新版本。落盘失败恢复记录的旧数据，并按原规则保留或重新打开未保存画布。其他题目及外部更新继续走原有详情加载逻辑。
- 横竖屏切换时保留正在关闭的画布，退出结束后按当前窗口尺寸布局。材料与题目画布使用同一个分栏宿主命名空间，保留各自的画布标识。退出期间进入后台时，由同一次退出负责保存最后一笔。已开始的后台写入先完成，再保存退出时的快照；后台按会话类型写入，分栏笔迹不写到普通笔迹字段。
- 11.27.3 首次 Xcode 归档在退出保存和切后台保存的闭包处提示类型推断不明确。两处共用普通画布保存入口，由该入口明确声明主线程提交回调的类型。验收以原 iPad 目标归档成功为准，交互与数据路径沿用上述规格。
- 验收：普通错题不画直接关闭、画完立刻关闭、连续撤销后关闭、清空后关闭并重进。关闭期间验证纵向滚动和再次打开的状态，重进确认最后一笔或清空结果。资料分析双栏分别画在材料和题目，关闭重进核对各自笔迹。模拟写入竞争时保留后写的题干或笔记；写入失败保留笔迹可重试。分别记录点击至遮罩消失、页面恢复交互和笔迹持久化时间。
