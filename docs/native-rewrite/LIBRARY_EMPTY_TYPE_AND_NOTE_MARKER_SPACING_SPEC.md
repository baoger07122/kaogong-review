# 错题题型筛选与笔记列表间距

## 无具体题型时收起题型栏

- 入口为行测错题列表的题型筛选栏，包括判断推理下的形式逻辑及其他支持题型筛选的范围。现有行为只要存在未归类记录，就会渲染「未分类」，即使当前范围的具体题型目录为空。
- 先按当前科目和模块取已有题型。具体题型集合为空时整行隐藏，卡片使用现有无筛选栏的间距。存在具体题型时保持原控件的字号、位置、顺序和窄窗口横向滚动，继续按当前筛选条件决定是否需要附加「未分类」。数量关系复用同一条件。
- 存在已选择的「未分类」但其入口已失效时，恢复当前范围的默认全部状态。切回之前浏览的真题或模拟题范围时也检查恢复的选择。记录的题型 ID、题型管理和编辑入口沿用原有数据。
- 验收：打开没有具体题型但已有错题的形式逻辑，卡片显示且没有题型栏。为该模块新增题型后确认该题型与必要的「未分类」同时出现。选择「未分类」后删除最后一个具名题型，确认题型栏消失且卡片恢复当前范围全量；切换真题和模拟题复查。

## 明确圆点前后与编号后的间距

- 入口为支持文档式排版的错题笔记编辑、阅读。录屏 28 秒画面中，正文左缘在 x≈374，圆点可见墨迹约为 x382–387，列表正文首字在 x≈401，`1.` 的末点约在 x389。录屏有缩放和压缩，以这些比例校准本应用的 16 pt 正文。
- 圆点仍为 6 pt 实心圆。以列表正文起点和列表层级为锚，前留 9 pt、后留 15 pt，正文制表位为 30 pt。圆点横向位置按缩进计算，圆点纵向位置取首行中心。编号和正文之间至少留 12 pt，短编号沿用 30 pt 基准，长编号为文字让位。折行使用相同的正文起点。
- 编辑、读取旧笔记、粘贴、回车续项使用同一段落样式。原有缩进层级、列表标记语义、光标和退格路径沿用现有实现。
- 验收：在 iPad 同宽截图比较圆点左侧、圆点右侧、`1.` 和 `10.` 后的距离及折行对齐。分别检查缩进与取消缩进、窄分屏、保存后重开。录屏像素和 iPad pt 采用比例换算，最终呈现以 iPad 截图为准。
