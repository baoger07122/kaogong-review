## 逐项实现

1. **统一题型管理**：设置页以单一「题型管理」入口列出五个行测科目；数量关系直接进入题型目录，其余科目按模块进入目录。判断推理、常识判断使用独立稳定目录；编辑器可选题型，题目详情显示分类，错题列表复用现有题型筛选。保留言语理解和资料分析原目录键与历史题目字段。
2. **数量关系的题型迁移**：改名会迁移题目模块、考点目录、分组、错因标签目录及对应错题引用；删除将错题改为未分类、移除考点目录，并把错因标签及分组迁到未分类。相关修改在一个 SwiftData 事务中保存，失败时恢复本地记录快照。
3. **考点与错因标签选择和筛选**：选择框把完整名称胶囊与搜索输入自动换行显示，每项提供可访问的圆形移除按钮；保留完整引用身份，支持跨题型选择、分组及现有候选管理操作。题库列表的「筛选标签」分别提供考点和错因标签筛选；同类多选按任一匹配，两类条件同时启用时按交集，标签过滤按模块、题型与名称完整匹配。
4. **独立错因标签字段**：草稿、错题载荷和详情编辑增加 `mistakeTagRefs`；旧记录缺失时按空数组读取。新增字段沿用整题保存边界，与考点引用、旧错因文字字段分开保存。标签类别、题型范围、分组和排序相互隔离，改名、删除、迁移只更新匹配来源的引用。
