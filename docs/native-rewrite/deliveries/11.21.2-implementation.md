# Native 11.21.2 实现与预发布记录

执行依据：[11.21.2 批次规格索引](../NATIVE_11_21_2_SPEC.md)及其中列出的八份实现规格。

## 本批实现结果

1. **涂鸦工具栏：** 统一速算、错题、题库、申论材料等涂鸦入口的原生画笔／橡皮控制；按规格统一退出按钮反馈。详细触摸和 PencilKit 行为待实机确认。
2. **错题详情进入与编辑返回：** 卡片点击以预热快照立即打开详情，详情读取和编辑返回继续按记录身份更新，避免切题时复用其他题目内容。快速连续点卡、失败重试和保存返回待实机确认。
3. **标签管理：** 错题考点／错因标签支持长按管理，编辑返回维持详情稳定。长按手势和保存后的实际列表状态待实机确认。
4. **图推默认选项：** 新建图形推理错题在空选项条件下预填可编辑 A–D；已有数据、恢复草稿和用户输入沿用原值。各入口录入与保存待实机确认。
5. **原生拖动排序：** 题型和每日待办排序改用原生拖动交互，移除了旧的手动重排列表实现。拖放边界和持久化待实机确认。
6. **图推闪卡：** 采用紧凑题干／选项布局并加入题图 PencilKit 涂鸦；布局原型随代码提交。翻面、画笔、局部橡皮和不同尺寸表现待实机确认。
7. **考点通用分组：** 选择器与标签管理以「通用」作为默认组；当前分组内筛选和新增，保留既有分组 ID、标签和错题引用。新增的 `LibraryKnowledgePointPolicyBehavior.swift` 用例覆盖通用组、跨组搜索、删除组及同名组情形。
8. **图推题干预填：** 最终代码仅在「平面图形」新建题型预填可编辑题干；此前对整个图推模块的预填已在后续提交收窄。非平面类型、手动编辑和草稿恢复待实机确认。
