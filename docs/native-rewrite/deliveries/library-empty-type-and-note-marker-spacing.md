# 错题题型筛选与笔记列表间距交付

- 按[实现规格](../LIBRARY_EMPTY_TYPE_AND_NOTE_MARKER_SPACING_SPEC.md)，题型筛选栏以当前范围有具体题型为显示条件。有具体题型的范围继续按已有记录和当前筛选条件决定是否显示「未分类」。失效的「未分类」选择在目录更新或切回来源时恢复为默认全部。
- 错题笔记将圆点两侧设为 9 pt 和 15 pt，圆点按正文制表位定位。序号按实际宽度为正文预留至少 12 pt，保留 30 pt 的基准和折行对齐。间距调整同时经过已有笔记载入与新建列表路径。
- 两个 Swift 文件的语法解析与基线对比无新增问题，`git diff --check` 通过。Windows 工作区缺少 Xcode，形式逻辑筛选交互和列表实际像素对比待 iPad 环境验收。
