# 错题保存返回与笔记输入交付记录

对应 [实现规格](../ERROR_EDIT_AND_NOTE_INPUT_SPEC.md)。本轮发布版本：11.28.1 / Build 170。本轮在当前工作区实现。上一轮涂鸦退出改动仍在同一工作区。

发布 run `46096362479` 的域行为检查和编译通过；错题编辑与笔记 XCTest 因工作流遗漏 library build 分支、测试 App 未生成而未得到断言结果。随后 run `46098449898` 的聚焦模拟器步骤仍未完成，run `46099529386` 在归档时报告关联错题视图的 Swift 类型检查超时；已在发布修复提交中将候选项的显示文本收敛为明确字段，待最终归档确认。

| 项目 | 实现与核对 |
| --- | --- |
| 错题保存 | 原始载荷已经解码且字节匹配时，保存复用草稿。事务内继续校验版本与载荷。现有数据准备、索引和关联更新保留；SwiftData 事务执行持久化，只在事务成功后交接。新增原始载荷校验及详情交接日志。 |
| 返回详情 | 保存结果只匹配同一题、同一版本和完整载荷。正文、标签和工具可直接使用这份数据，再同步到详情状态。未换的图片沿用缓存标识，换图使用新标识。 |
| 单元格输入与上下键 | 正文和活动单元格分别持有原生输入焦点。进入单元格时跳过正文的失焦发布，组字中跳过程序化光标调整。屏幕上下按钮与外接键盘未带修饰键的上下方向键共用切格路径，透传组字阶段的按键。 |
| 引用与光标 | 引用统一显示左侧 3 pt 灰线，最少缩进 14 pt，去除引用中的中性底纹并保留有色高亮。首次打开编辑时在获得焦点后恢复位置，正文单击按 TextKit 算出的字符位置放光标。 |

本地差异检查与 Swift 语法基线对比通过。XcodeGen 测试文件引用正确。富文本工具栏的已有源码检查在规范化 Windows 换行后通过。通用表单源码检查在基线和工作区均因真题编辑器选项使用 `1...3` 行、检查期待 `1...4` 行而失败。

新增的 XCTest 覆盖有效保存结果、旧草稿拒绝、引用样式属性、单击放置光标以及屏幕上下键切换并继续输入。Windows 无 Xcode，尚未运行 XCTest 或原生编译。录像中的保存耗时、拼音首键和候选、外接键盘切格与触摸定位，需在 iPad 上复验。首字母重复的具体系统事件顺序尚未通过实机确认。
