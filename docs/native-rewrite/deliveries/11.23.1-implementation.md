# Native 11.23.1 实现与预发布记录

执行依据：[11.23.1 批次规格索引](../NATIVE_11_23_1_SPEC.md)及其中列出的八份实现规格。

## 本批实现结果

1. **错题笔记表格：** 富文本编辑与详情显示支持横线分隔表格及单元格换行；新样式限于指定笔记表格路径，其他富文本样式沿用原规则。
2. **待复习词语网格：** 压缩待复习词语卡片的布局，保留现有列数和不同宽度适配。
3. **词语库卡片摘要：** 摘要优先使用实际释义／辨析正文，兼容旧词条与新版辨析，并保留全文搜索。
4. **错题详情菜单：** 删除重复的重做入口。
5. **首页倒数日：** 删除操作移入编辑菜单并增加确认步骤。
6. **词语复习编辑入口：** 关闭详情菜单后再导航到编辑器，避免菜单覆盖跳转造成卡住或闪退。
7. **词语详情排版：** 正文保持现有字体字重；表格字调至 13 pt 并以实际可用宽度换行。用户确认的对照图路径记录在排版规格中。
8. **复习关联错题与评价：** 关联错题导航按错题 ID 打开并返回原词条；评价成功后关闭当前词条详情、只推进一次，下一词进入回忆卡，末词返回待复习页。失败保存、普通返回和编辑取消不应推进队列。
