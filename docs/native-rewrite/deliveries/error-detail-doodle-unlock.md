# 错题涂鸦退出锁定整改记录

对应[实现规格](../ERROR_DETAIL_DOODLE_UNLOCK_SPEC.md)。本轮发布版本：11.28.1 / Build 170。

| 项目 | 实现与检查 |
| --- | --- |
| 关闭操作 | 错题入口松手直接调用关闭。原生画布接收待处理的撤销或清空并安排快照编码后，结束涂鸦界面，释放返回、翻题、模式切换、正文与菜单。源码核对了无改动直接关闭、快照已交接及交接失败后的提交分支。 |
| 保存和并发 | 耗时的笔迹编码沿用后台队列。分栏绑定持有原会话和原布局。退出时保留后台任务保护，失败允许重试原记录。额外记录 SwiftData 提交用时，便于区分界面限制和写盘耗时。 |
| 快速点击 | 退出后允许立即请求同题编辑或再次涂鸦。写入完成后处理仍属于当前题的请求，离开页面或切题时清除请求。保存失败时显示底部重试提示，草稿保留在本次应用会话内。 |

本地 `git diff --check` 通过。Tree-sitter 与基线对比未新增解析诊断，解析详情文件时两份输入均跳过既有的 `storedSplitDoodleValues` 函数以规避级联诊断。XcodeGen 配置已检查，新增用例验证快照编码未完成时退出状态，以及失败后对同一份内容重试的状态流程。

本机为 Windows，Xcode 编译和 XCTest 均未执行。还需在 iPad 或模拟器核对快速返回、翻题和关闭材料后的最终笔迹，并测量恢复交互的实际耗时。本轮未发布。
