# Native 11.20.2 implementation record

## Scope

- Word library editing: separate native HTML snapshot eligibility from the bounded fallback parser. Native snapshots now require balanced HTML, no unparsed native markers, supported serializable attachments, and the existing byte, text, image, and attachment bounds. Fallback editing retains its stricter lossless checks.
- Xingce inline note layout: ensure TextKit lays out the full current document before measuring, size from the current text storage and end caret, and invalidate the cached height only when the measured content height changes. Added content-free diagnostics for edit requests, storage length, selection, revision, focus, lock, and height. The stabilized measurement mode is enabled only for the Xingce detail note; other editor layouts keep their existing measurement path.
- Xingce inline note saving: edits remain in the live editor until the user taps “完成”. Backgrounding, leaving the view, restoration, and programmatic tool transitions save only a recoverable local draft; programmatic transitions wait for that local write. Monotonic draft versions and deletion fences prevent delayed writes from resurrecting a discarded or committed recovery draft. Formal record and index writes remain on the user-confirmed completion path. Recovered version conflicts show both bodies and require a choice before editing.
- Shenlun inline note callers keep their existing automatic-save behavior.
