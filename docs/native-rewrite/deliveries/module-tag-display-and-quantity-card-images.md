# 标签展示与数量关系题卡配图交付

执行依据为[标签展示范围与数量关系题卡配图](../MODULE_TAG_DISPLAY_AND_QUANTITY_CARD_IMAGES_SPEC.md)。

- 标签展示入口移到题型选择器上方，弹窗、编辑、详情和错题卡片共用模块范围。数量关系的题型与未分类共用科目设置，旧题型设置一致时继承，冲突时沿用默认值。新增测试覆盖共享、模块隔离、重开后读取及旧设置迁移。
- 数量关系错题卡片复用资料分析综合题的首图预览及列高估算。图片按题目科目加载，支持现有图片列表与旧单图字段。索引确认无图时跳过图片载荷，未分类筛选可用性检查也无需读取图片。
- 常规错题卡片底部右侧显示实际保存的录入年月日及时分。优先取记录字段，兼容载荷里的创建时间。缺少创建时间的错题编辑后仍省略此行。回归测试覆盖已有时间、载荷时间及缺值编辑。
- 本地通过变更文件的语法解析对比、XcodeGen 测试目标配置检查与 `git diff --check`。Windows 工作区缺少 Xcode，XCTest 和 iPad 交互尚未运行。待按规格验证标签开关同步、首图顺序、录入时间与窄窗展示。
