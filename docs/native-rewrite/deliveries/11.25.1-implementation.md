# 原生 11.25.1 实现与预发布记录

## 实现范围

- 宽窗口两栏等宽；纸面按材料栏宽显示，支持滚动、捏合缩放、倍率菜单和原生无障碍缩放入口。
- 行内编号、句间编号与小数采用不同占格规则；复盘格子纸按题目上限和已用格数显示。
- 「对照答案」为交卷后首栏；成绩在答案页顶部；疑惑和心得在独立复盘页保存。
- 发布工作流仅对本轮申论更改运行既有领域检查、指定申论 XCTest 与新增的 iPad 模拟器交互验收，不运行无关模拟器组。

## 预发布检查状态

- Windows 本地 `git diff --check`：提交前完成。
