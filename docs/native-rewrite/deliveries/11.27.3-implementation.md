- 数量关系卡片在未选题型时将题型移到右上角，使用灰字。再次点已选的题型可清除筛选。规格、实现检查和原型见[数量关系题型与套卷复盘备注](../QUANTITY_CARD_AND_EXAM_REVIEW_SPEC.md)和[本地交付记录](quantity-card-and-exam-review.md)。
