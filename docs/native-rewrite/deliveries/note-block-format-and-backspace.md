# 笔记格式与退格退出交付

- 按[实现规格](../NOTE_BLOCK_FORMAT_AND_BACKSPACE_SPEC.md)调整错题笔记的无序列表、有序列表、引用、标注和分割线。编辑和阅读共用段落语义与 TextKit 2 绘制，编辑态为未输入内容的列表和引用提供占位。列表正文在固定位置对齐，长编号按字形宽度调整制表位。
- 列表、引用和标注段首的退格命令先退出当前格式，保留正文及相邻段落。框内引用逐层退出，分割线可在下一段起点退格移除。列表回车续项，同一缩进的连续编号随插入顺延。输入法候选期间由系统处理按键。
- 保存和加载路径新增段落元数据，并兼容旧引用、列表和字符分隔线。格式编辑使用原有文本存储替换、撤销注册及延迟序列化。新增元数据往返检查和空列表退格的 iOS 交互用例。
- Swift 语法解析与基线对比无新增问题，`git diff --check` 通过。当前 Windows 环境缺少 Swift、Xcode 与 iPad，新增用例和目标编译尚未运行。输入法、撤销、格式重开、窄分屏与实际动画效果待 Apple 环境验收。
