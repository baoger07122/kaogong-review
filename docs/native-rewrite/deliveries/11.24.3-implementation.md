# 原生 11.24.3 实现与预发布记录

执行规格：[原生 11.24.3 批次规格](../NATIVE_11_24_3_SPEC.md)。本轮基于已核对的 11.24.2 发布基线整合申论离线复盘及正文/答题纸补充，不包含功能开发工作树中的未提交文件。

## 本轮变更

- 申论练习支持按作答次数独立保存、复盘、评分、心得、疑惑、续写、重做和历史补录；单题与套卷中的单题共用流程。
- 材料、作答要求和复盘对照显示按纸面宽度布局。粘贴可整理断行并保留段落。
- 新增正文顶格与段首粘贴清理；正数字数上限后提供 100 个浅蓝备用格；段首序号合排、段末句号与前字同格；完成作答后可切换格子纸或普通文本。
- 发布工作流会在申论相关源文件变化时选择 iPad 模拟器，只运行 `ShenlunPaperRepositoryTests` 与 `ShenlunWorkspacePaperLayoutTests`。既有固定领域行为检查仍按仓库工作流执行。

## 检查状态

- Windows 发布工作树的 `git diff --check` 和文件范围核对：发布提交前完成。
- 本机无 Xcode / `xcodebuild`，不声称已在本机编译或运行 iOS 测试。
- iPad 模拟器测试、设备目标归档和 IPA 上传结果：由本轮唯一自动 Workflow 完成后写入 `11.24.3.md`。

- 发布提交 SHA、Workflow run ID、Release 和 IPA 实际下载状态：发布成功后由生成的交付记录及本次执行结果确认。
