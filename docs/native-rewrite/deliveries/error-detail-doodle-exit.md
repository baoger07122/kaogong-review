# 错题涂鸦退出整改交付记录

对应 [实现规格](../ERROR_DETAIL_DOODLE_EXIT_SPEC.md)。本轮变更保留在当前工作区。

| 验收项 | 实际实现 | 检查依据 |
| --- | --- | --- |
| 点击退出后恢复阅读 | 退出状态撤下工具栏和全屏交互遮罩。画布宿主保留到笔迹快照完成，正文纵向滚动先恢复。快照完成后恢复题目操作，落盘期间暂停重开涂鸦。 | 核对根覆盖层条件、普通及分栏画布的命中测试、详情导航与滚动状态。 |
| 有改动和无改动的保存 | 普通涂鸦后台准备笔迹和兼容预览，再提交一次记录。无改动跳过写入，清空会移除旧预览。分栏按布局和画布保存。 | 核对保存分支、字段映射、写入前后的完整数据比对及失败回滚。 |
| 保存后恢复详情 | 同一题的在用快照与写入前的版本一致时，提交成功后直接使用已保存数据。其他版本继续走现有加载路径。 | 核对持久化回调、当前题目与版本检查，以及原加载任务命中现有快照的分支。 |
| 分栏及生命周期 | 材料画布的宿主标识与工具栏预期一致。待快照期间保留分栏布局。退出任务覆盖最后一笔的后台保存，已有后台写入先完成，分栏保存按已提交画布内容推进基准。 | 核对分栏宿主匹配、旋转处理和两条保存路径的先后关系。 |

已通过 `git diff --check`。用 Tree-sitter 对四个本轮变更的 Swift 文件做了基线对比。解析详情文件时在两份输入中同样跳过既有的 `storedSplitDoodleValues` 函数，以排除该函数导致的级联诊断。改动没有引入额外的解析诊断。

当前环境为 Windows。iOS 编译、退出后的实际交互时延、即时关闭后重开确认最后一笔、资料分析双栏分别保存、退出时旋转或切后台，以及写入失败重试待 iPad 或模拟器验证。
