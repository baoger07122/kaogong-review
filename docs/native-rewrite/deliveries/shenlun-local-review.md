# 申论单题离线复盘交付记录

- 首次进入未做题会打开第 1 次作答。复用原答题纸、字数投影和键入组件。完成后右侧进入本次复盘；继续作答、返回复盘、切题和材料锚点通过工作区状态切换。
- 复盘提供疑惑结论与核验状态、手动分数与来源、复盘心得和参考答案对照。可回看独立历史、重做、续写及补录。单题与套卷内单题共用此流程。套卷轮次和整卷心得留在后续范围。
- 原按题记录读取为一条兼容记录。作答保存按独立记录 ID 和修订号更新，新记录加入备份导入导出。增加两项 SwiftData 测试覆盖旧作答、多次作答、补录顺序、重复写入、备份、复盘草稿和清空分数。
- Windows 本地通过 Git 差异检查。对八个修改过的 Swift 文件进行语法树检查，未发现新增语法解析问题。此环境没有 Xcode，仓库单元测试和原生编译需在 macOS 运行。
- 发布执行时检查编译归档与可下载 IPA。iPad 验收关注窄分屏阅读定位、红格点击与中文输入法提交、交卷后的疑惑和复盘。测试与发布结果由发布记录补充。
