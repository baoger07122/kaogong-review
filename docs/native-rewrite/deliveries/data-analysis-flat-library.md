# 资料分析取消题目分组交付

- 按[实现规格](../DATA_ANALYSIS_FLAT_LIBRARY_SPEC.md)把行测侧栏、错题列表和模块复习概览收为「资料分析」单入口。隐藏录入、详情、横向预览及关联题列表上的旧模块。错误类型设置直接打开本科学习目录。
- 新资料分析题按科目保存。旧题编辑保留载荷和索引的原分组值，历史标签目录继续用于解析原有标签。已有分组的草稿可从科目入口恢复，卡片按题干图片及材料显示。标签展示开关使用科目范围。
- 在既有测试目标补充用例，覆盖旧分类和无分类记录的统一作用域、标题、图片、旧题原字段与新题保存。通过 Swift 语法解析对比及 `git diff --check`。Windows 工作区没有 Xcode，未运行 XCTest 或 iPad 交互验收。待核对窄窗、旧标签选择、错误类型排序与草稿恢复。
