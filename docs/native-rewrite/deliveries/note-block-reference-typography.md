# 笔记段落样式校准交付

- [实现规格](../NOTE_BLOCK_REFERENCE_TYPOGRAPHY_SPEC.md)以录屏 6、16、28 秒附近的画面为测量依据。圆点可见直径约 6 px，列表正文起点距段落左缘约 27 px，标注内边距约 19 px，独立引用的竖线约 22 px 高。将这些比例换算为本应用 16 pt 正文下的布局目标。
- 编辑与阅读统一使用 6 pt 矢量实心圆和至少 30 pt 的列表正文制表位。文本标记保留在选择和存档中。正文折行保持悬挂缩进，有序编号保留正常字形。
- 引用改为 25 pt 左缩进和 3 pt 竖线。标注采用 1 pt 边框、10 pt 圆角和 22×20 pt 内距。分割线在 28 pt 区域内居中绘制。浅色和深色使用分别设定的灰阶。
- Swift 语法解析与基线对比无新增问题，`git diff --check` 通过。当前工作区为 Windows，iOS 编译与截图比对待 Apple 环境完成。重点验收显示比例、首行圆点替换绘制、窄分屏折行、深色对比和旧笔记重开。
