# 数量关系卡片与套卷复盘备注本地交付

本轮依据见[实现规格](../QUANTITY_CARD_AND_EXAM_REVIEW_SPEC.md)。

- 数量关系卡片已用 11 pt 次级灰字替换原蓝底题型，保留现有标签组件和选择、取消选择交互。具体题型与「未分类」筛选时隐藏重复题型。
- 套卷列表压缩汇总与成绩排版，并加入默认开启、可持久切换的备注预览。详情为导航页，支持在模块成绩上方编辑「本套表现」及「下次怎么改」。备注专用保存保留旧富文本、成绩和关联错题，冲突时保留草稿。全卷编辑器沿用原入口。
- Git 差异检查通过。Swift 语法解析相对基线无新增诊断。浏览器在 1100 px 与 390 px 验证了原型的题型选中与取消、备注填写保存、列表展开及显隐；这些结果仅对应 HTML 原型。
- 增补了两个 XCTest 用例，用于验证旧备注兼容、两类保存互不覆盖及并发草稿冲突。本地 Windows 无 Swift/Xcode，XCTest、原生编译及 iPad 的布局和交互待验证。
- 改动留在本地，应用版本未递增。
