## 按规格对照

1. **错题详情首屏与读取。** 已改为等完整载荷和必需关联题内容可用后再呈现答案、选项与详情，加载时在题目位置使用短提示；保留失败重试和请求隔离。载荷解码改为同版本共用请求/缓存，详情分页版本不再随请求 ID 抖动。源码检查与 Xcode 归档通过；未在设备上验证首开、再开、横向翻页、慢加载和答案颜色稳定性，也没有可据以报告点按时长的实机测量。
2. **错题笔记安全编辑。** 纯 Swift 解析器扩展了 App 导出段落、字形/颜色、链接和附件标记处理；只在全篇格式和附件可完整保留时提供编辑，其他内容继续保留原文。发布工作流中的 `NativeRichTextNoteBehavior` 行为检查通过。未用用户设备上的三条历史笔记进行完成、重开和附件视觉往返验证。
3. **复习中的原词条完整操作。** 复用词语详情和现有编辑、删除、迁移、关联错题流程，保留原词条 ID 与当前复习状态；不在浏览/编辑时隐式提交评价。Xcode 归档通过；菜单和复习会话返回尚未实机点验。
4. **从所选待复习词条开始整组复习。** 队列从被点击条目开始，后续项按原序排列，之前条目放到队尾；继续沿用评价成功自动推进和去重状态。工作流中的词语复习领域检查通过，但没有独立的 UI 自动化覆盖该新入口；“中间项开始、连续复习到末项”的交互仍待实机验收。
5. **首页关联错题涂鸦。** 首页导航栈接入根层共享涂鸦会话，复用同一工具栏、画布与保存回调。源码归档通过；笔迹保存、返回后重开、切题、切标签和 iPad 分屏未实机验证。
6. **错因文案。** 资料分析及数量关系详情展示缩短为「错因：」；编辑表单和详情快捷编辑字段使用「错因说明」。字段与布局未改。发布归档通过，尚未在窄分屏逐页点验。
7. **查看释义直达词条和历史筛选。** 复习卡片可直接进入同一词条详情，并在详情内提交评价；历史提供全部及四类词语筛选。词语复习领域检查和 Xcode 归档通过；各筛选状态、删除中词条跳过及连续评价返回未实机验收。
