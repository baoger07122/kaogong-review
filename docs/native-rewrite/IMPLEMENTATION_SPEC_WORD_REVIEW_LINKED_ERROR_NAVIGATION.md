# 词语详情关联错题跳转与箭头位置

## 1. 首页 → 词语复习 → 查看释义／辨析 → 关联错题

- 源码原因。复习使用 `navigationDestination(item:)` 打开词条详情，但该详情未传入关联错题回调，点击时落到首页 `AppRoute` 的值路由。SwiftUI 在已有视图目的地时压入值路由，会先移除上层视图目的地，破坏此处的词条返回层级。[Apple 导航说明](https://developer.apple.com/documentation/swiftui/understanding-the-navigation-stack)
- 目标。点击关联错题行或行尾箭头，直接打开相同记录 ID 的现有错题详情。返回后保留当前词条、复习位置和评价按钮；打开和返回均不提交评价。
- 实现落点。由 `WordReviewWordDetailDestination` 在现有子页面状态中按错题 ID 打开 `HomeErrorDetailDestination`，复用首页现有的题目读取、编辑与涂鸦。排队打开词语编辑或已在打开子页时忽略重复请求。题目已删除时沿用「错题已删除」提示。
- 验收。进入至少关联两道题的词条。分别点摘要和箭头，核对打开的题号，返回核对同一词条和进度。检查快速双击、错题编辑／涂鸦返回、删除题目后的提示。对照行测词语库入口仍能打开关联错题。

## 2. 词语详情 → 关联错题行

- 现状。箭头作为竖向堆叠的最后一项占据一行，位置低于题目摘要。
- 目标。左侧为现有来源和两行以内的题目摘要，右侧为箭头，和左侧文字块垂直居中。维持来源字号 11 pt、摘要 13 pt、箭头 9 pt 半粗，沿用现有颜色和上下各 7 pt 留白。文字与箭头间距 8 pt，整行最小点击高度 44 pt。窄窗保持箭头可见，题干在左侧换行截断。
- 实现与验收。复用 `WordLibraryRecordDetailView.linkedErrorRow`，将箭头移入横向布局。截图相同位置核对箭头在行的右边且垂直居中，单行、多行、窄分屏和多个关联项均可点击。

## 3. 词语复习 → 词语详情 → 不会／模糊／掌握

- 源码排查。三种评价用同一保存入口。保存成功后原实现清空详情绑定，同时改动队列和根视图显示状态。详情没有用自身的返回动作关闭。关联错题又从同一详情跨到首页值路由，两处导航共用一个栈。设备上再次显示词语详情的具体过程待验证。
- 目标与落点。评价成功后，用当前词语详情自己的返回动作退出，再推进一次队列。普通返回、打开关联错题和取消编辑不推进队列。当前词删除或跳过，仍复用相同的返回与推进流程。保留同一个提交 ID，校验评价对应当前已揭示词条，忽略过期事件或重复触发。保存失败留在当前详情并提示。页面样式和现有按钮沿用。
- 验收。从至少两词的队列开始，分别点击三种评价，检查详情只退一层，立即回到下一词回忆卡。最后一项回到「待复习」。打开关联错题再返回后重复测试，核对仍只有一条评价历史。检查快速连点、保存失败重试、普通返回、编辑后保存及跳过。

## 交付记录

- 关联错题已接入词条详情内部导航，按选中的题目 ID 打开现有错题详情。共用的关联错题行已将箭头移到右侧并垂直居中。
- 三种评价成功后由当前详情关闭自己，详情绑定清空后队列推进一次。普通返回沿用当前词条，保存失败保留提示和重试。
