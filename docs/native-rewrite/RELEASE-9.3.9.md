# 9.3.9 / Build 32 — 估算练习与退出响应

## 本轮范围

- 估算题按网页版排列为两行：A→B、C→答案。保持手动确认及现有数字键盘。
- A 随机覆盖 101–999；手动区间优先，未定义时明确标注系统估算（最近整十数或 125 的倍数）。B、C 保持三位数；通过选择 C 的有效范围让 D 也保持三位数，计算 D=C×B/A，不篡改计算结果。
- 估算表新增/编辑输入起点、终点、估算值；自动升序、包含两端、重叠/越界校验、覆盖数量和未覆盖区间。空表不再伪造用户定义。
- 三位数除一位数的除数限定 2–9；普通练习不再受到上一次自定义数字设置影响。
- 返回按钮内部提供 44×44 点击区；退出确认改为就地窗口，与切回主页同一次无动画状态更新，继续练习保留输入。未完成退出不保存历史。

## 定位与验证

视频可见原生确认框消失后仍短暂停在旧题目上，但没有触点记录，不能凭视频认定数秒延迟或音频阻塞。

DEBUG 测试保留原系统确认框作为对照，记录触摸开始、退出处理、主页首次显示回调和音频清理耗时；发布 IPA 不启用触摸探针或诊断文字。

自动测试覆盖全部 899 个源数字、比例极端值、表格校验、历史兼容、普通/自定义除数，以及真实模拟器点击、取消保留输入、连续进出和两行估算页面。模拟器时序不能替代用户 iPad 的流畅度验收。
