# 原生 11.24.2 实现规格

## 发布范围

- 基线：Release `native-v11.24.1`，应用版本/Build `11.24.1 / 163`。
- 目标：应用版本/Build `11.24.2 / 164`。
- 执行代码：以下六项已分别按其实现规格完成，本次基于 11.24.1 发布基线整合。
- 保持原工作树中的未提交 AGENTS.md、历史原型及其他素材不进入本次提交。

## 1. 错题笔记表格行内编辑与流程图

- **入口与现状：** 行测错题详情 → 错题笔记；插入表格目前使用独立表单，正文没有结构化流程图编辑。
- **目标：** 在正文光标处插入或直接编辑表格，并在正文中插入纵向流程图；输入、附件提交、草稿恢复、撤销及复制沿用现有笔记流程。
- **实现依据：** [行内表格编辑与流程图规格](IMPLEMENTATION_SPEC_INLINE_NOTE_BLOCK_EDITING.md)。
- **边界与验收：** 最少 1×1、最多 16 行 8 列；流程图至少 1 步、最多 16 步。按该规格验收中文输入、Tab/Shift–Tab、行列与步骤增删移动、撤销、窄分屏、与其他附件共存、保存重开及纯文本/富文本复制。

## 2. 标签类别迁移与表格单元格上下导航

- **入口与现状：** 行测标签管理只支持在当前类别维护标签；错题笔记表格没有同列上下换格按钮。
- **目标：** 考点和错因标签可以互迁并在事务中维护目录、分组及题目引用；表格键盘工具条增加同列上/下换格，流程图不显示该控制。
- **实现依据：** [标签迁移与表格导航规格](IMPLEMENTATION_SPEC_TAG_CATEGORY_AND_TABLE_NAVIGATION.md)。
- **边界与验收：** 目标同名时按规格合并；旧名称引用有歧义时停止迁移，不部分写入。首末行方向禁用；切换先提交输入，目标空格光标在起点、非空格在文字末尾。验收双向迁移、同名和旧引用情形，以及中文输入、首末行、多行和窄分屏。

## 3. 表格笔记保存校验与模块标签展示

- **入口与现状：** 错题笔记保存版本可能因非笔记题目字段变化冲突；标签展示开关按题型独立。
- **目标：** 仅在笔记基准可验证且正文未变时将笔记写入最新题目载荷；模块标签展示设置在同模块题型间共享，其他模块隔离。
- **实现依据：** [笔记保存与模块展示规格](IMPLEMENTATION_SPEC_NOTE_TABLE_SAVE_AND_MODULE_TAG_DISPLAY.md)。
- **边界与验收：** 笔记冲突、旧草稿无法证明基准时保留草稿并进入原冲突路径；标签已有模块设置优先，旧题型设置一致时可继承、有冲突则采用默认值直到显式保存。验收普通/粘贴/行内表格保存重开、非笔记属性更新、正文并发修改及模块间开关行为。

## 4. 错题卡片考点与错因图标

- **入口与现状：** 行测错题卡片标签使用统一深色灯泡；只有错因时也可能预留图标空间。
- **目标：** 考点使用强调蓝灯泡，错因使用 C 款路径纠偏细线图标；只有对应标签组存在时才展示，并使卡片高度估算一致。
- **实现依据：** [卡片标签图标规格](IMPLEMENTATION_SPEC_CARD_TAG_ICONS.md)。
- **边界与验收：** 图标 11×11 pt、线宽 0.75 pt，与现有 11 pt 图标位及 6 pt 间隔一致；验收两类、单类、无标签、长标签换行、窄分屏和读屏类别语义。

## 5. 笔记保存与设置中的科目导航

- **入口与现状：** 错题笔记恢复草稿和正式保存分属异步流程；设置页科目行直接挂视图，未统一使用设置导航栈。
- **目标：** 短文字及表格笔记的恢复、完成、保存草稿都以实际存储回执和笔记基准协调；题型管理的五个科目通过类型化设置路由打开。
- **实现依据：** [笔记保存与题型管理科目跳转规格](IMPLEMENTATION_SPEC_NOTE_DRAFT_AND_TYPE_SUBJECT_NAVIGATION.md)。
- **边界与验收：** 同内容新草稿可接受；内容、题目或笔记基准不同则保留较新草稿；兼容旧 JSON。验收短文字/表格完成后重开、后台切换、并发与旧草稿恢复；逐一验收五科跳转及返回后继续进入模块和题型管理。

## 6. 发布版本字段

- **入口与现状：** `native-ios/project.yml` 为 `MARKETING_VERSION: 11.24.1`、`CURRENT_PROJECT_VERSION: 163`。
- **目标：** 更新为 `11.24.2 / 164`，供自动版本校验、设备目标归档、IPA 和 Release 标记使用。
- **验收：** 检查配置字段一致；发布工作流通过版本检查、设备目标归档与资源核验，并生成对应版本 IPA。
