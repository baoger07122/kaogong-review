# 标签长按管理与编辑返回稳定性

## 1. 错题编辑的标签长按

**入口和原因。** 错题新增或编辑 →「考点」／「错因标签」。候选项原菜单挂在禁用集合选择的外层集合视图，每个标签自己的按钮只处理短按。搜索框内的已选标签只提供取消选中。

**实现。** 为候选标签按钮直接挂原生长按菜单，保留「重命名」「修改分组」「调整顺序」「删除」在原有适用范围内。搜索框内已选的已入库标签长按也能重命名和删除；短按照常取消当前题选择。沿用胶囊、尺寸、系统菜单字体和红色删除动作，窄窗口自动显示系统菜单，无新增常驻按钮。未入库的历史引用可按叉移除。

**保存边界。** 重命名和删除仅针对实际来源科目、模块、题型和标签类别，沿用已有标签库事务与确认。同步已选列表和编辑草稿中的同源引用；标签改动立即保存，取消错题编辑不撤销当次标签库操作。删除确认说明会解除引用，题目仍保留。

**验收。** 两类标签分别短按、长按候选和已选项；验证重命名保留选中、删除确认后解除引用，取消确认保持数据，另一个题型同名标签不受影响。检查搜索结果、窄分屏和只读筛选。

## 2. 错题编辑返回和冷读首屏

**入口和原因。** 错题详情进入编辑，保存后系统返回。保存改变记录版本，当前详情的完整快照被严格版本规则隔离，下一轮载荷读取前只剩等待占位。另一路冷读曾计划先画题干，选项和属性后到，会使题干位置有可能改变。

**实现。** 同一记录刷新期间保留上一份完整详情用于阅读，暂时禁用其修改、笔记、刷题作答及涂鸦操作。按记录键确认仍是同一题，普通错题读取新载荷后整块更新。关联题库的错题在更新前同时解析新载荷所需的题库内容。切换题目绝不能从其他记录沿用详情；读取失败继续给出重试。普通卡片继续立即导航和后台预读。完全冷读时等待完整快照一次呈现，撤掉仅题干和之后补选项的过渡，快速读取阶段无独立加载页，慢读在详情原区域用已有 11 pt 提示。

**验收。** 已打开的题编辑题干、正确答案、标签后保存。返回期间旧详情仍完整且不可写，随后整页显示新数据。验证取消编辑、题库关联题、失败重试、刷题保持答案隐藏、冷开及滑到其他题不串数据。
