# 申论文字材料粘贴排版整理

- **入口与现状**：申论录入或编辑题目 → 给定材料 → 文字材料。系统粘贴带入 PDF 的固定行宽换行，阅读页把每一行当段落缩进。用户需要手工合并断行、恢复段落。
- **目标与界面**：每份文字材料编辑框下方左对齐显示「整理排版」，使用应用强调色、辅助操作的 13 pt 中等字重及至少 44 pt 高的触控区域。整理后同一位置显示「撤销整理」。去除确定属于排版的行内换行，段落之间保留一空行。阅读页使用原有纸面首行缩进。空材料禁用整理；已符合规则时反馈「排版无需整理」。窄窗口按钮留在本材料的编辑框下方。
- **整理规则**：本地处理当前材料的文本。空行、段首缩进、材料标题和编号项是明确的分段依据。文本没有这些分段信息时，按短行的中文句末标点辅助识别段尾。逗号后和词语中间的断行合并，分开的中文右引号与标点连回前文，连续英文词之间保留空格。算法保留正文字符，不猜测或删减页码、水印。无法从纯文本准确还原原 PDF 的所有段落。
- **状态与保存**：用户主动点击才整理，修改当前材料的编辑草稿。撤销恢复该材料整理前的全文及换行；手动编辑后结束本次一键撤销状态。复用材料版本字段和「保存题目」提交。PDF、图片、题干和答案的内容不经过此规则。
- **验收**：把包含词中断行、句末断行、跨行右引号和多段落的申论 PDF 文字贴进「材料 1」。整理后检查文字顺序、段间空行和阅读页缩进；撤销核对原输入，再点整理并保存、重新进入。另检查已显式空行或缩进的段落、编号项、英文、两份材料分别操作、无文本禁用及窄窗口。
