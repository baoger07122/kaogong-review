# 选择考点弹窗的已选标签实现规格

状态为原型已确认，待应用实现。适用入口为行测 → 资料分析 → 新增错题或编辑错题 → 考点。共用同一考点弹窗的入口按本规格回归。

已确认图纸见[单选「倍数」](prototypes/knowledge-point-selected-labels/01-selected-times.png)和[窄窗口多选](prototypes/knowledge-point-selected-labels/02-selected-wrapped.png)。两图是同一弹窗的两种状态，其他候选名称用于演示。

## 现有行为

截图中的「知识点错误」出现在灰色输入框里，下方已勾选的是「倍数」。本地基线 `248adf1` 中，`VerbalReasoningKnowledgePointSelectionDialog.selectedReferenceChips` 采用单行横向滚动，`selectedTitle(for:)` 会将类型或来源拼在考点名前，每项末尾已有移除按钮。分屏时，此布局可能先显示类型，考点名和移除按钮留在可见区域之外。

## 界面与布局

1. 从上到下依次为「选择考点」标题和右上角关闭按钮、错误类型或题型说明与跨类型入口、灰色搜索框和右侧「新增」、候选考点、已选数量与「清空」、底部「确定」。资料分析的示例说明为「当前错误类型 · 知识点错误」。「知识点错误」归属类型说明行。
2. 灰色搜索框内从左到右显示已选标签和「搜索或新增考点」。标签内容直接取考点全名 `reference.name`，例如「倍数」，末尾带一个始终可见的圆形 ×。类型、模块和分组信息仍由各自的现有入口展示。候选区用勾选色和 ✓ 表示已选，底部只承载数量、清空和确认操作。
3. 复用 `NativeEditorDialog` 的 420 × 468 pt 首选尺寸、17 pt semibold 标题、30 pt 圆形关闭样式及蓝色主按钮。搜索框沿用原生灰色底、12 pt 圆角、12 pt 水平内边距、44 pt 最小高度和 14 pt 常规输入文字。已选标签使用 11 pt medium、`AppTheme.accent`（#007AFF）和约 10% 强调色背景，约 28 pt 单行高度，标签之间约 6 pt。多行标签的高度跟随文字增加。移除使用圆形 × 图标，点击区域延伸到标签尾部。为两个叉分别提供清楚的辅助功能标签。
4. 灰框内所有项目左对齐，以实际可用宽度换行。标签放不下时整项移到下一行。单个名称宽于整行时，文字在标签内换行并为尾部 × 保留空间，完整显示标点及原有文字。输入区剩余宽度足够容纳提示文字时紧跟标签，否则移到下一行。「新增」与灰框第一行对齐。极窄时允许上方类型说明和跨类型入口各占一行。
5. 窗口或键盘压缩可用高度时，正文可纵向滚动，用户仍能到达每个已选标签、搜索输入和候选列表。标题关闭按钮与「确定」保持可操作。空选时灰框直接显示搜索输入，底部显示「已选 0 项」。

## 数据与操作

- 在 `native-ios/Sources/Features/Library/LibrarySelectionDialogs.swift` 调整 `LibraryKnowledgePointSearchInput` 和 `VerbalReasoningKnowledgePointSelectionDialog.selectedReferenceChips` 的布局。采用可测量剩余宽度的前导对齐换行布局，搜索输入作为最后一个项目。将用于候选消歧的来源标题和已选标签的名称显示分别绑定到各自视图。检查 `LibraryRecordEditorView` 与 `LibraryRecordDetailView` 的共用入口。
- 用现有有序 `selected` 保存弹窗内的选择。已选标签的身份沿用完整的 `LibraryKnowledgePointReference`，含 `module`、`typeID`、`name`。同名不同源分别渲染、分别移除，辅助功能可读出来源。沿用原有选中顺序与旧考点兼容逻辑。
- 点候选切换该引用的状态。点灰框某项的 × 移除这一个引用，同一轮刷新该候选的 ✓ 与已选数量。搜索和切换题型、错误类型或分组时，已选区持续显示所有已选引用。清空只清空这一轮选择。
- 错题表单内，「确定」通过现有 `commitSelection` 将引用写入 `draft.knowledgePointRefs`，同步 `draft.knowledgePoint` 显示值。整题用原有「保存」写入记录。详情等已有 `onCommit` 的调用方沿用其提交边界。提交报错时留在弹窗并保留选择。右上角 × 放弃弹窗内尚未确认的选择。考点库的新增和管理走各自现有保存流程。

## 验收

1. 在 iPad 的资料分析新增错题中选「知识点错误」，打开「考点」，点「倍数」。检查灰框显示完整的「倍数」与小 ×，上方有独立的错误类型说明，下方「倍数」带 ✓，底部显示「已选 1 项」。点小 ×，核对候选取消勾选且数量归零。
2. 在同一弹窗内选至少五项，其中一项使用比单行还长的完整名称。缩窄 iPad 分屏并弹出键盘，验证标签向下排布、文字和每个 × 都可到达、候选仍可搜索和点击。清除搜索输入后，原有选中状态仍在。
3. 跨类型或分组分别选标签，再切回当前类型。检查灰框仍有所有选项。若两来源存在同名标签，移除其中一个后进入两个候选范围分别核对勾选状态。用带「，」的标签验证名称整体显示与移除。
4. 编辑一题已有「倍数」的错题。取消选择后先点右上角 ×，重开确认原选择还在。再取消后点「确定」，核对表单更新，保存整题并重开确认持久化。验证详情共用弹窗以及已有旧考点的错题也能显示与确认。
