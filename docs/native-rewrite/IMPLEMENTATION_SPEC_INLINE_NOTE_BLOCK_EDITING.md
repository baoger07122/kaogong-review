# 错题笔记正文内表格编辑与流程图

沿用《错题笔记表格样式与正文内编辑设计》和已讨论的 `inline-note-table-flow.html` 原型。

## 1. 在正文内编辑表格

- 入口为行测错题详情 → 错题笔记 →「插入」→「表格」，以及已有表格。当前入口打开独立编辑表单。
- 在光标处插入 2×2 表格并聚焦第一格。点击已有表格，原位显示原生多行输入框。沿用白底浅灰横线、12 pt 字号、首行半粗及现有自适应列宽。当前格细蓝边及淡蓝底，长字在输入时可滚动，提交后按内容增高。点其他格或外接键盘 Tab / Shift–Tab 换格，Return 在格内换行。
- 键盘工具条提供「表格操作」与「完成单元格」。可在当前格后增加行列、删除当前行列，保留至少 1×1，最多 16 行 8 列。保留其他格与加粗样式的对应关系。复用正文撤销处理单格提交和结构调整。
- 按笔记会话与附件实例替换附件。切格或笔记「完成」时提交输入法合成内容后更新快照。附件位置变化时保留编辑输入和原附件。单格与附件总量沿用现有安全读取上限，越限提示缩短并保留输入。保留现有正文前后关系、草稿与「完成」提交方式。
- 验收：插入表格、粘贴带粗体表格、在旧表格的非首格用中文输入，Tab 换格、从中间增删行列、撤销并保存重开。检查长格在窄分屏的换行与滚动。

## 2. 从正文插入纵向流程图

- 从同一个「插入」菜单选「流程图」，在光标处新建两步并聚焦首步标题。浅灰卡片圆角 12 pt、内边距 10–12 pt，标题 15 pt 半粗、说明 13 pt 次要色，居中换行，相邻步骤使用灰色向下箭头连接。跟正文同宽，留空的标题以步骤序号作为提示。
- 共用原位输入与附件提交机制。键盘工具条的「流程图操作」支持在当前步后增加、删除、上移和下移。最少一步，最多 16 步。
- 复用现有附件编码，可选呈现字段区分流程图，两列映射标题、说明；无字段的附件沿用表格。纯文本复制按顺序保留步骤标题及说明，富文本复制可在错题笔记间保留结构。读态、草稿恢复与重新编辑沿用附件读取路径。
- 验收：在两段文字中间插入并分别修改标题、说明，增删及移动中间步骤，复制到纯文本及另一条错题笔记。与旧表格、图片共存时保存重开，核对顺序和格式。

## 交付检查

- 已接通已有表格的点格进入、新建后的首格聚焦、行列增删和现有笔记的保存与撤销路径。结构调整和格式对应关系已加入现有富文本回归用例。
- 已接通流程图插入、标题及说明编辑、调整步骤、读态渲染、安全恢复与复制。加入流程图标记与旧表格兼容的回归用例。
- `git diff --check` 通过。Swift 语法树与修改前相比无新增解析问题。Windows 上未运行 Swift 编译、自动化用例或 iPad 交互。待设备编译及实机核验中文候选、外接键盘、窄分屏定位、撤销以及混合笔记的复制和保存重开。
