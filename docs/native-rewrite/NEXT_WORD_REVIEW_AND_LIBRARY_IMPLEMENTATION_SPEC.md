# 下版词语复习与词语库优化规格

记录于 2026 年 11 月 20 日。用户已明确授权将本规格四项统一派发给 Luna，接续当前热修后的词语版本。

## 1. 首页「词语复习」显示待复习总数

**现状。** 首页的 `HomeView.featureGrid` 用 `HomeFeature` 渲染快捷入口，当前无数量角标。「词语复习」页的 `WordReviewOverviewSnapshotBuilder` 已按计划到期日、暂停状态、有效词条与类别生成 `dueWordIDsByCategory`。已有计划的类别归属随词条当前记录读取。

**目标。** 在首页「词语复习」紫色图标右上角加红底白字角标，显示所有类别的待复习总数。复用现有 56 × 56 pt 图标区域，圆角角标最小 18 × 18 pt，数字 10 pt semibold、等宽数字，内容增宽时使用胶囊并允许显示完整数字。角标不改变快捷入口的布局和点击区，零项时隐藏，窄窗口保留原有排列。语音读出「词语复习，待复习 N 项」。

**计算与状态。** 同一个词条 ID 只计一次，辨析组按一项计。合并所有类别的当日和逾期待复习 ID，排除未到期、暂停、无效和已删除的词条，首页数量与复习页的同日清单一致。复用复习到期规则及已有快照能力，处理复习完成、暂停／恢复、新增或迁移词条、导入、跨午夜和回到前台。当前复习页可自动补建计划，首页计算必须覆盖相同资格和到期日语义。使用可复用的轻量计划与词条元数据或共享快照按需刷新，避免在首页视图构建或待办输入时解码完整词语库、读取复习历史或写计划。

**验收。** 放入两种词条与一个辨析组，混合今天到期、逾期、未到期、暂停。核对「词语复习」各类合计和首页角标。完成、切换暂停、返回首页及跨日后核对刷新，清空待复习后角标消失。

## 2. 旧词语原地手动迁移

**现状。** `LibraryComparisonDocumentProjection` 会从旧结构字段临时生成新版正文。已有 `comparisonDocument` 优先，包括明确被清空的空内容。`LibraryRecordRepository` 只在编辑后的正文与计算出的原正文不同时写入新字段，因此旧结构已经可显示，打开它或照原样保存仍可能没有真正迁移。编辑器和列表以当前四类标识读取词条，无法识别的旧类别不应被静默归成成语。

**用户操作。** 行测 →「词语库」→ 现有「…」菜单 →「迁移旧词语」。展示可识别的未迁移条目及待确认类别的旧条目，每行显示标题、原类型、迁移状态，使用现有列表样式。点开一条，查看原内容和新版预览，选择目标类型，必要时修改新版正文，然后点「确认迁移」。原条目详情的「…」也可进入同一迁移流程。列表与预览复用词语库的标题、正文和卡片样式，两份内容在窄窗口纵向排列。仅迁移本次确认的一条，返回可继续处理其他词条。

**映射与保存。** 复用正文投影把旧辨析的共同语义、词义及核心侧重、统一情境、具体区别、判断提示和核心区别对应到新版结构。按旧数据中可验证的类别标识预选，未知或冲突类型由用户选定。成语释义、实词释义优先复用有效的现有释义正文。预览需要能检查表格、粗体和附件。确认后在同一条记录写入对应新版正文和类别，即使正文等于临时投影也要持久化，更新索引。保留原始结构字段、已有附件、词条 ID、创建日期、词语复习计划及历史、关联错题。无需复制成新词条后再删旧条目。

**边界。** 新版正文已经存在时保留用户内容。明确的新版空值继续作为用户选择，无法断定是旧占位的数据只提示人工核对。无法安全转换或原题已变更时保留已有条目，展示异常和重试入口。取消或保存失败不写入，成功后该条移出未迁移队列，重复确认不会新增重复词条。

**验收。** 各取一条旧成语辨析、旧实词辨析、旧释义及未知类型词条。检查预览、取消、按原样确认、重开原 ID、迁移后分类、关联及复习记录。检查已有新正文、明确清空和异常附件三种情况。

## 3. 已有词语可更改类型

**现状。** `LibraryRecordEditorView.wordFields` 在新建时显示类别选择，已有词条只展示「类别」属性。`switchNewWordCategory` 也限制为新建。11.12.5 的规格曾这样约定。释义正文使用 `meaning` 及旧字段兼容，辨析正文使用 `comparisonDocument`，只改类别会导致目标类别从不同字段读出空正文或旧内容。

**目标。** 打开词语 →「编辑」→ 点「类别」，提供实词、成语、实词组辨析、成语组辨析四类单选，复用新增词语的顺序与文案。现有「类别」属性样式和位置保持，行至少 44 pt 可点击，选择菜单显示当前勾选，窄窗口可触达全部选项。选择即时反映在草稿，点编辑页「保存」生效。编辑期间可切回原类别，点返回时沿用现有取消／放弃本次修改处理。

**内容和关联。** 切换类型前取得最后的富文本编辑快照及输入法提交结果。释义与辨析互转时同步把当前正文写入目标类别需要的字段，避免旧字段覆盖刚编辑的内容。同类内变更也保留富文本、附件和关联。保存同一词条时一次更新 `category`、`type`、正文和索引，词库与复习清单移动到新类别。保留 ID、计划、历史和关联。只读或加载中的旧正文若不能做安全转换，展示具体原因并进入手动迁移预览。保存失败保留全部草稿和原记录。

**验收。** 已保存词条从成语改实词、释义改辨析，再从辨析改释义。检查保存前后标题、最终正文、图片和表格，确认分类及复习归属变化、无重复条目。覆盖改类型同时编辑末尾文字、放弃修改、重新打开、保存失败和带旧结构的词条。

## 4. 评价后自动进入下一项

**入口与现状。** 首页 →「词语复习」→ 复习词条 → 查看释义或辨析。`WordReviewView.submit` 提交「忘记／模糊／掌握」对应的评价后，把结果赋给 `savedHistory`，页面随之显示「已记录」、下次日期及「下一组／完成」按钮。现有 `advanceSession` 只会在点击该按钮时执行。

**目标。** 每次选评价后，用现有事务记录反馈和下次计划。写入成功即调用现有推进逻辑，显示本次队列的下一词条或辨析组，回到未展开释义的首屏。同一队列评价完最后一项或只复习一项时直接回「待复习」列表。移除逐条阻断的「已记录」确认页和「下一组／完成」按钮。原评价按钮、标题、进度、卡片布局和窄窗样式保持现有组件，实际评价及下次计划可在「历史」查看。

**保存与边界。** 沿用当前评价、初学／到期规则及 `submissionID` 去重。只允许当前项一次提交，快速连点不得重复记历史或越过下一项。保存失败停在当前已展开的词条，显示已有错误提示，用户可重试。结束、换项或返回后的过期回调不得推进另一会话。别把当前复习队列扩到用户没有开启的其他类别或词条。

**验收。** 连续复习三项，分别点三种评价，前两项写入后直接到下一项，最后一项回「待复习」。检查历史各有一条正确的记录及下次计划。单项复习、快速连点、保存失败重试和窄窗均复核。
