# 原生主导航候选设计

本目录仅保存视觉方案，不代表正式代码已经修改。

- `A-classic-floating-capsule.png`：经典悬浮胶囊，最接近旧版，选中区域较大。
- `B-compact-floating-island.png`：紧凑浮岛，占用最少、整体更轻。
- `C-liquid-glass-dock.png`：灵动玻璃 Dock，保留蓝色胶囊并增强层次与光感。

共同约束：

- iPad 横屏约半屏宽度。
- 整体导航不铺满、不贴左右边和底边。
- 五项均显示图标与文字：首页、学习库、复习、套卷、设置。
- 只动画蓝色选中胶囊，图标与文字本身不闪动。
- 用户确认设计后才进入 Swift Playgrounds 互动预览和正式代码实现。
