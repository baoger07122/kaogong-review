# 统一涂鸦工具栏

## 1. 工具、控制器和画布

**入口与原因。** 速算练习、结果和历史详情的涂鸦；行测错题、题库及旧版申论使用的涂鸦覆盖层；申论材料批注。已经共用 `NativePencilDrawingEditor`、`PencilDrawingController` 和 PencilKit 的画笔／局部橡皮，差异来自各页手写的按钮集合。速算用可切换的橡皮按钮，缺独立画笔按钮；申论材料的工具集合也不同。

**目标和落点。** 在共享原生涂鸦组件中提供一套「退出、画笔、橡皮擦、撤销、清空涂鸦、画笔调节、手指涂鸦」工具栏。沿用错题的胶囊、32 × 44 pt 按钮布局、14 pt 半粗符号、主题蓝选中状态和无障碍标签。画笔按钮直接切回原笔色和笔宽；橡皮按钮直接选用局部擦除。设置继续用共享调节面板。统一从已有笔色、笔宽和橡皮大小偏好开始。画布算法继续共用 PencilKit 的 `PKInkingTool(.pen)`、`PKEraserTool(.bitmap)` 和已有撤销、序列化逻辑。

**适配与数据。** 速算和错题占原有工具栏位置，退出分别沿用当前题的临时画布提交和错题原有保存。题库及旧版申论经既有错题覆盖层获得相同工具。资料分析可在退出旁提供「材料／题目」按钮。申论材料保留图层入口和页面／图层保存，宽窗口同排、窄窗口将共享工具放在右侧第二排。更窄时工具可横向滚动，退出固定可见。独立画布不共用同一条笔迹记录；设置、样式和处理路径集中，答案输入锁、按页／图层归属、失败留在当前会话等规则继续沿用。

## 2. 退出按钮反馈

**原因与实现。** 速算退出使用普通按钮，错题退出只短暂淡入背景，随后直接拆下工具栏。共享退出在按下时即时缩至 90%、下移 1 pt，并显示 16% 主题蓝高亮，拖离取消时 0.14 秒复位。正常短点后保持反馈 80 毫秒，再调用原有提交与退出。启用「减弱动态效果」时只用颜色反馈。反馈与提交期间只受理一次退出，离开后销毁待执行的反馈任务。保存失败恢复退出可用状态。

## 验收

- 速算、错题、题库和申论材料各打开一次，核对标准按钮、选中颜色与退出位置。依次画线、选橡皮、直接点画笔画线、撤销，核对切换逻辑及区域擦除一致。
- 速算作答中和结果页验证关闭再打开笔迹行为、退出后恢复输入。资料分析分栏与申论材料图层验证写入正确目标及保存失败后的可重试退出。
- 快速轻点、按住拖离、连续点退出，在窄分屏和减弱动态下核对视觉反馈和一次提交。保留既有速算和错题退出测试标识。
- 本地检查后保留待发布提交。收到「发布执行」再交 Luna。
