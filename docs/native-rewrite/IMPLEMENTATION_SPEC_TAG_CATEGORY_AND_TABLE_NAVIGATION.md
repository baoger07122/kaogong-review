# 标签类别迁移、行测卡片标签对比与表格换格

## 1. 考点与错因标签互迁

- 入口：行测相关的「标签管理」→「考点」或「错因标签」→ 标签行右侧更多菜单 →「移到错因标签」或「移到考点」。原来只能在各自类别管理或改变题型。
- 更多按钮使用系统省略号、12 pt 中等字重、40 pt 最小宽度及 44 pt 高度。菜单为原生样式，窄窗口保留标签换行。沿用居中确认组件，显示目标类别、现有同名项是否复用及更新的错题数量。
- 迁移保留科目、模块、题型和名称。目标同名时合并，保留其排序与分组；新增目标放在默认分组。移除来源分类及分组成员，保留分组本身。标签管理保留当前范围，成功行内提示可在目标分段查看。
- 已关联错题逐题从对应引用字段移除，并写入另一字段。更新考点兼容字段和查询索引，保留错因说明和其他内容。带完整引用的跨题型关联仍保有原标签范围。旧资料仅凭名称时只在题目同模块且候选唯一时自动转换；同模块旧引用涉及同名歧义则整次暂缓。独立「笔记」记录的文本属性不迁移。
- 重新核对确认时的范围、受影响条目及目标同名状态。双目录、来源分组与关联错题在同一个事务里写入，失败保留原状态。
- 验收：在平面图形考点里选一枚标签迁成错因标签，再迁回来。检查题目、两类筛选、换页后目录、同名合并、未分类的旧引用，以及同名不同题型仍分别保留。

## 2. 卡片里的两类标签

- 此项先按行测首页参考截图做两张卡片原型。考点和错因标签在卡片顶部都采用当前标签的字号、间距、圆角、描边粗细及排布，考点在前。同一张原型同时展示两类和只存在一类的卡片。
- A 方案只将考点描边改为蓝色。B 方案只将考点文字改为蓝色。错因标签使用深色文字和浅灰边框。原型确认后再选定样式及更新卡片代码。

## 3. 错题笔记表格上下换格

- 入口：行测错题笔记 → 点正文表格内的任一单元格。键盘工具条增加上／下箭头，位于「表格操作」和「完成单元格」之间。
- 使用系统 chevron.up 和 chevron.down，同列上下换行，首末行对应方向禁用。切换前提交当前输入，切换后光标位于目标格文字末尾，空格置起点。原有 Tab 顺序换格及点击定位光标沿用。窄窗口使用图标控制，流程图不加换格按钮。
- 验收：在第二列分别向上和向下换格，输入中文并核对已提交内容和光标落点，检查首行和末行、空格、多行文字及窄分屏。

## 交付检查

- 已接通两个类别的迁移动作及确认。复用原标签目录、分组和错题索引；新增引用策略回归用例覆盖双向、跨模块完整引用、旧名称和重名合并。
- 表格输入工具栏已接通上下换格，切换后请求目标格文字末尾光标。此处随正文内表格编辑的待发布改动一同构建。
- 两张原型已用同一页面、题目及标签布局渲染，分别为 `card-tags-a-blue-border.png` 和 `card-tags-b-blue-text.png`。
