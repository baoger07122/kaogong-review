# 标签管理空旧考点的默认选择

- 入口为首页「标签管理」的「考点」分段。原先题型菜单固定列出「旧考点」。初始选择与菜单使用不同的可用题型规则，有时已选题型在菜单中找不到，标题又回退成「旧考点」。
- 使用同一份可用题型决定菜单、默认选项、标题和新增考点的保存范围。当前模块有题型时默认第一项。只有旧目录仍有考点时才列出「旧考点」。仅剩历史分组时用「通用考点」进入其管理范围。有旧考点时仍可手动打开。删除或迁走当前范围最后一个旧考点后，自动回到第一项可用题型。
- 当前模块既无可用题型也无旧考点或分组时，隐藏无选项的题型控件，标题显示「模块 · 考点」。可按现有方式向模块新增考点。资料分析等科目的可用通用类型与模块专用类型同列，言语理解沿用模块专用题型。错因标签菜单保留「未分类」及其原有含义。
- 复用现有选择器和管理页排版、字号、颜色及窄窗布局。只调整展示和会话选择，目录、标签关联、自建分组和迁移保存机制照常。
- 验收时分别打开有题型无旧考点、同时有两类、只剩历史分组和完全为空的模块。确认默认值、菜单及保存范围一致。切换科目和分段，删除或迁走最后一个旧考点，核对选择随数据更新。资料分析有通用错误类型时可在菜单找到。错因标签仍可切换到「未分类」。
