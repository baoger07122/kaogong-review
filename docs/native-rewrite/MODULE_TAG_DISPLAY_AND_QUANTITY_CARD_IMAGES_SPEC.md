# 标签展示范围与数量关系题卡配图

## 1. 标签展示只按模块生效

- 入口为「首页 → 标签管理 → 标签展示」。当前言语理解、判断推理、资料分析和常识判断已按模块保存。数量关系把题型名称存入记录的 `module` 字段，展示设置仍会为各题型单独读写。
- 标签管理弹窗、错题编辑与详情的属性区、错题卡片顶部使用同一展示范围。普通科目按「科目 · 模块」取值。同一模块内所有题型和未分类共用。数量关系没有独立模块，所有题型和未分类共用「数量关系」范围。题型选择、改名和删除不改变展示范围。标签内容、目录、题目关联和标签筛选继续使用原有数据。
- 复用现有 420 × 420 pt 居中弹窗、滚动正文、原字号和颜色。管理页的「标签展示」入口沿用 14 pt 半粗体和至少 44 pt 点击高度，置于题型选择器上方。普通科目的范围文案使用科目与当前模块名称，例如「判断推理 · 论证推理」。数量关系显示「数量关系」。窄屏保留现有科目和模块选择器纵排。
- 保留各模块已有设置。旧数量关系题型中已有设置一致时继承这套值，存在冲突时用现有四项默认值。显式保存的共享设置优先。沿用点击即时保存，写入失败时保留旧设置。无需修改题目数据。
- 验收时从数量关系「几何问题」打开「标签展示」，开启卡片顶部的「错因标签」，切到「和差倍比」和未分类检查同一设置与题卡效果，再重开应用检查持久化。对同一普通模块两个题型与另一个模块分别确认共享和隔离。检查错题详情和编辑页的属性开关。

## 2. 数量关系错题卡片显示题干图片

- 入口为「行测 → 错题」卡片列表，覆盖「全部」、数量关系的默认列表和已选题型列表。当前数量关系的题干图片不会进入卡片快照。
- 在标签区之后、题干文字之前复用资料分析综合题的首图规则。使用原顺序的第一张题干图片，按已有宽度比例与卡片内容宽度左对齐、保持图片比例。沿用 10 pt 圆角、0.7 pt 描边、题卡尺寸对应的高度上限和现有加载状态。窄窗口随卡片宽度适配。详情仍可查看所有题干图片。
- 用题目本身的科目读取现有 `images` 或旧 `image` 字段，不依赖当前题型筛选。索引确认无图时跳过图片载荷读取。单独保存的选项图片不属于此预览。无图时不渲染图片或占位，图片加载失败沿用现有提示。多列布局按首图规则估算卡片高度。
- 验收时给一条数量关系错题添加两张题干图，返回卡片确认仅展示首图。分别从「全部」、未选题型和对应题型查看。替换或删除第一张图后再次查看，并检查无图题目、旧单图记录和资料分析综合题。

## 3. 错题卡片显示录入时间

- 入口为「行测 → 错题」的常规卡片，覆盖真题、模拟题、全部和已选科目、模块、题型。错题保存时已有 `createdAt`，详情区会读它，常规错题卡片目前没有显示。
- 在题干、错因和提醒等内容后添加一行，右对齐，显示「录入 2026-11-28 14:35」。用设备时区，采用 24 小时制与等宽数字，字号 11 pt 常规字重，次要文字色，与上一组间距 8 pt。窄卡片保持单行，必要时缩小至 85%。多列卡片高度估算计入时间行。图形推理的默卡和闪卡继续沿用各自布局。
- 读取记录本身的 `createdAt`，缺失时读取旧载荷中的同名字段，支持 ISO 8601（含毫秒）与 Unix 秒或毫秒。只有更新时间或创建时间不可解析时省略整行。新建记录保存录入时间。修改已有错题时保留原值，旧错题缺失录入时间时不以编辑时间补填。已存在的日期按当前存储值显示。
- 验收时新建真题和模拟错题，核对卡片显示的时间。修改并保存题干，核对时间保持一致。导入只有载荷创建时间、只有更新时间的两条记录，检查前者显示、后者省略，后者编辑后仍省略。检查窄窗口及带图数量关系题卡的时间行。
