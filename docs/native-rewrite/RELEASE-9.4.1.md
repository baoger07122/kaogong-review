# 9.4.1 / Build 33 — 涂鸦导航与结果页校准

## 本轮范围

- 速算练习返回键撤销额外的 44×44 视图放大，恢复系统工具栏原有外观；颜色继续继承 App 的系统蓝强调色，不单独写死。
- 涂鸦模式保留底层返回箭头的视觉位置，但禁用其触摸和辅助功能焦点，退出涂鸦必须使用右上角退出按钮。
- 涂鸦操作合并为间距更紧凑的一排，并为左右工具栏预留对称空间；打开或退出涂鸦时禁用整页布局动画，标题保持原位。画笔调节仍从底部出现，取消后收起。
- 速算结果页按网页版校准标准文案、固定行高、表头和辅助文字灰阶，以及底部按钮文字颜色；保留原网页定义的字号和字重。

## 验证

- 源码契约覆盖返回键禁用、标题对称预留、无整页涂鸦过渡动画、结果表格行高与文案。
- GitHub Actions 使用 Xcode 26 构建并运行 iPad 模拟器交互测试后发布未签名 IPA。
- 不清除或迁移用户数据，不改动独立预览版及其他未提交设计工作。
