# 错题笔记表格样式与正文内编辑设计

## 本轮实现

- 入口为行测错题详情 → 错题笔记 → 插入表格或打开已有表格。表格当前是 TextKit 的单个附件，普通正文光标无法进入其中的独立单元格。新增和点击附件时当前编辑器用独立表单编辑结构化数据，表单提交后按附件标识替换回正文。截图里的灰底、竖线和密集行距来自 `.system` 样式，表单里的省略号来自 130 pt 固定宽度的单行输入框。
- 行测错题笔记的阅读、编辑、草稿对照和失败回退预览统一复用 `.libraryContent` 表格。白底、12 pt 单元格文本、首行半粗、只保留浅灰横线，沿用其列宽分配和最小行高。保持已有单元格、粗体、行列数量、表前表后正文和附件标识。
- 行测表格的现有编辑面板使用同样的白底横线。每列按可用宽度分配，单列至少 108 pt，列多时可横向滚动。格内 12 pt 文本可自动换行，首行半粗。保留 row/column 控件、提交失败提示和当前笔记的「完成」保存边界。
- 验收覆盖新建、直接粘贴和重新打开旧表格。核对读写两态、长单元格、窄分屏及多列滚动、行列调整、取消、保存后重开。其他入口继续使用各自表格样式。

## 正文内编辑与流程图设计

- 点击单元格时在它原来的位置输入。当前格给细蓝边或淡蓝底反馈，其他格维持白底横线。增删行列收进选中表格后的操作菜单。退出单元格或点笔记「完成」时，先提交输入法合成文字与单元格更改，再保存笔记。失败保留原格内容与待保存输入，支持撤销。
- 在「插入」里增加「流程图」。第一版采用纵向顺序，每步可填标题和可选说明。浅灰圆角块内标题半粗、说明灰色，步骤用向下箭头连接，跟正文同宽，窄分屏按内容换行。支持插入、直接编辑、增加、删除和调整步骤。从旧笔记读取时保留结构化内容，纯文本导出按顺序保留标题及说明。后续实现需要覆盖跨段粘贴、连续中文输入、硬件键盘换格及混合图表笔记保存。
- 本轮落实表格样式与单元格换行。正文内编辑和流程图仅交互设计原型，尚未接入 App。

收到「发布执行」后交 Luna 构建。
