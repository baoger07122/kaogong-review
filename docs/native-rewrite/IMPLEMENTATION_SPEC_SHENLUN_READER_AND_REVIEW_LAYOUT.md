# 申论材料缩放、格子纸与复盘布局

## 工作区和材料

- 入口为申论单题和套卷的题目详情。现有宽窗口按 55:45 分栏，材料从 55% 起步，底部常显滑杆。宽度至少 680 pt 时，分隔线两侧平分可用宽度；窄窗口保留纵向布局与快捷入口。
- 材料、作答要求、PDF 和图片初次展示时横向铺满材料栏，保留纸张比例。100% 对应当前栏宽。使用系统滚动视图支持单指拖动阅读、双指捏合缩放。滚动或捏合时在材料视口左上角暂显百分比按钮。点开使用原生弹出菜单切换 50–300% 或适应宽度；交互结束后约 2 秒隐藏。底部只保留翻页。旁白可通过材料区的缩放辅助操作调整。材料切换、翻页、改尺寸与批注共用同一原始纸面坐标。
- 验收时在横屏测量分隔线位置，打开长文本、PDF 和图片核对首次铺宽；滚动、捏合、选倍率、恢复铺宽、翻页和旋转，检查纸面位置。检查画笔与已有笔迹随页面缩放，以及分屏中的读写切换。

## 格子纸

- 沿用 25 列的红格和原字体。普通字符与合并编号共用同一字号与对齐基准；合并内容超出格宽时只压缩横向。行首与句间的「一、」「1.」「2.」等编号占一格，段内小数如 1.5 保留各字符的占格。段末和行末句号继续同格，原文保持完整。
- 作答时仍预留 100 格，备用与原格采用同样的线色和底色。交卷后的格子纸至少显示题目规定的格数，只额外显示已经用到的格子。未用备用区不显示；实际写过 100 格备用范围时，回看完整展示。已完成无字数上限的记录按实际占位铺纸，普通视图仍可看原文。
- 验收使用同段「1.经营管理强。2.质量管理强。三、其他。」和小数，核对编号的字号与占格。分别输入少于、等于和超过题目上限的文本，核对答题与回看中的格数、尾行和分页。

## 交卷后标签页和成绩

- 标签顺序为「对照答案」「本次复盘」「作答历史」，进入已完成作答、交卷或从历史选中作答时默认第一栏。成绩卡位于「对照答案」顶部，包含分数、来源和保存入口，原文/格子纸以及参考答案在其下方。复盘只显示疑惑、结论、心得和对应保存入口；历史记录上的成绩摘要继续用于区分各次作答。
- 答案页保存成绩、复盘页保存疑惑和心得，复用同一作答记录与草稿。保存一页时保留另一页未提交的输入；无效分数只影响成绩保存。保留旧分数来源及待复核状态。
- 验收同时修改分数与心得，分别保存并重开；检查 0 分、清空分数和无效分数，确认两边的未提交草稿独立保留。
