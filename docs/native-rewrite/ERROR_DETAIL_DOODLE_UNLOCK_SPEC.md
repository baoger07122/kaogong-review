# 错题涂鸦退出后的短暂锁定

- 入口为行测错题详情的「退出涂鸦」，覆盖普通题和资料分析分栏。11.27.3 会先撤下遮罩，再等 PencilKit 把最后一笔编码成字符串，期间返回、翻题、看／刷模式和右上角菜单仍受限。退出按钮还有 80 毫秒的固定等待。
- 错题工具栏沿用现有图标、尺寸、颜色、位置和按钮压下样式，松手后直接处理退出。原生画布在主线程先接收待处理的撤销或清空，并把完整的 PencilKit 快照交给现有编码队列。快照已被队列持有即可结束涂鸦界面。恢复导航、正文与工具栏操作。画布尚未交接且存在待处理笔迹时，走原有提交路径作为保护。
- 单份快照仍按原题和分栏布局保存。直接返回、翻题、收起材料或改变窗口尺寸时，编码从已取得的画布继续。保存沿用 11.27.3 的持久化和兼容字段。编辑同一道错题和再次打开涂鸦可以立即发起，等本次写入完成后使用最新记录。请求离开页面即取消，倾向使用用户最后点选的动作。
- 常规保存失败在底部显示可操作的提示，允许重试写入原题。失败草稿保留在当前应用会话，直到保存成功或用户确认放弃。提示用系统材质、系统字号及标准按钮，跟随底部安全区，窄窗口允许文字换行。保存失败不自动覆盖当前页面，也不跨题覆盖笔迹。
- 验收：普通错题画完马上关闭并立即返回或翻题，重新进入核对最后一笔。关闭后立即打开菜单、切换看／刷或滚动。马上点编辑或再开涂鸦，观察操作被接收且使用最新记录。分别测试无修改、撤销或清空后关闭、分栏画完马上收起材料、退出时旋转和切后台。模拟保存失败后切到其他题，重试确认只写入原题。记录松手至可交互及 SwiftData 单次保存耗时。
- 增加会话测试，暂停模拟的笔迹编码回调后断言页面已经恢复，再完成回调并核对保存对象。失败重试用例检查保存数据与原题标识。真机仍需验收真实 Apple Pencil 和导航交互。
