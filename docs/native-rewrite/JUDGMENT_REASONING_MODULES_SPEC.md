# 判断推理模块更名与新增

- 行测错题、笔记、便签中的「判断推理」将「逻辑判断」显示为「论证推理」，下一行新增同级「形式逻辑」。顺序为图形推理、定义判断、类比推理、论证推理、形式逻辑。复用原侧栏、模块菜单、详情标题及标签和题型管理组件的字号、颜色、间距、计数、选中态和窄窗标题缩放。
- 论证推理继续使用既有模块键 `逻辑判断`，保持旧题、题型、考点、错因标签、笔记及备份的归类。阅读、编辑、关联、复习、题型和标签管理均使用新显示名。形式逻辑写入独立模块键 `形式逻辑`，使用现有通用表单和独立模块筛选。既有题目可通过编辑选择迁入形式逻辑；自动导入的套卷成绩仍按原报告科目和模块名称统计。
- 两模块可分别创建、筛选错题和配置标签、题型。历史模块仍按原键管理，选择新模块时按现有规则清除不适用的旧题型。无数据时复用各页面原空状态。
- 验收：展开判断推理，检查两行顺序与窄窗显示。进入论证推理核对旧错题、考点、错因标签及自定义题型；打开详情、编辑和关联列表检查新名称。新建形式逻辑题型和错题，确认保存后只归入对应模块。将一题从论证推理手动改为形式逻辑，核对两边列表计数与题型。新增模型用例覆盖顺序、筛选隔离和旧题型命中。
