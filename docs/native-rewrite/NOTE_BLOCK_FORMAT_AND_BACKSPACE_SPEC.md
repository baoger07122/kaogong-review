# 笔记列表、引用、标注与分割线

- 入口为错题笔记和使用文档式笔记排版的富文本编辑器，兼顾保存后阅读。参考用户录屏约 4–6 秒的列表、12–17 秒的标注及引用、20–22 秒删除空引用和约 28 秒的分割线。在应用现有格式入口内提供「无序列表」「有序列表」「引用」「标注」「分割线」。无序列表按钮单击切换，旧空心圆、方块、短横线仍能读取，在笔记中统一为实心圆点。保留现有颜色、文字背景、表格和流程图入口。
- 笔记正文沿用 16 pt 系统字体。实心圆点使用 14 pt 常规字形及系统正文色，首行标记从 3 pt 起，正文及折行从 22 pt 起。编号用 16 pt 常规等宽数字及句点，长编号为制表位留足空间。固定制表位和悬挂缩进；旧列表原有层级可继续通过缩进调整。引用以 3 pt 深色竖线、22 pt 左缩进呈现。标注使用 0.8 pt 系统分隔色边框、8 pt 圆角，正文水平内缩 16 pt，上下留白。标注内可切换引用，形成框内竖线。分割线宽度跟随正文容器，用 0.75 pt 系统分隔色细线。空白编辑态显示系统次要色的「项目」或「空白引用」占位，内容提交时不写入占位文案。
- 格式命令只编辑选中段落的标记和段落属性，保留正文、粗体、链接和已有附件。分割线插在当前非空段落之后，光标移到线后。回车续项目或续编号，插入编号时顺延后面连续且同缩进的编号，空列表回车退出。在列表正文起点、引用或标注开头按退格，优先去掉当前格式，内容和上一段保留。框内引用先去引用，再去框。分割线后下一段的起点退格移除分割线。中文联想输入期间不拦截删除或回车。现有键盘保持当前焦点，使用原有 TextKit 局部更新、撤销及延迟序列化。格式工具栏用 0.14 秒短过渡，遵守减少动态效果。
- 保存使用应用现有 HTML 正文和段落布局元数据。`data-note-block` 保存引用、标注、标注内引用和分割线，`data-note-list` 区分列表与恰好以编号开头的普通段落。读取兼容旧 `blockquote`、旧字符分割线及旧列表标记。存档的竖线、边框和留白通过段落语义重建。空块的内部占位只供布局。复制、粘贴和撤销沿用编辑器操作边界。
- 验收时在 iPad 录入中文，检查连输拼音及删除不打断候选。验证普通、长行、两位编号、引用、框内引用及分割线在编辑、保存、重开和窄分屏显示。逐次按退格检查格式消退、文字保留和撤销恢复。测量工具栏切换、光标位置及键盘是否跳动。录屏像素尺寸不能直接等同于 iPad pt，动画流畅度以目标设备实测为准。
