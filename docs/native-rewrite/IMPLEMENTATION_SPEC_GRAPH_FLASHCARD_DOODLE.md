# 图形推理闪卡的紧凑版式与涂鸦

[已确认原型](prototypes/graph-flashcard-stem-above.png)

## 闪卡布局与翻面

- **入口与现状。** 行测 → 判断推理 → 图形推理 → 闪卡。目前图片在题干上面，卡片正面附带重复选项和 330 pt 最低内容高度。中间按钮进入编辑错题。
- **目标。** 正面依次呈现正面状态、题干、居中的完整题图。移除单独的选项列表及其闪卡内提交动作。题图自带的选项仍可见，原题的选项、答案与复盘记录仍按原模型保存。轻点卡面翻至答案和解析，轻点背面翻回。正常模式点击题图仍可全屏查看。
- **尺寸。** 沿用白底 22 pt 圆角、18 pt 卡片内边距、辅助字和 14 pt 正文。正面头部留 44 pt 给翻面提示或右对齐的现有涂鸦工具条。题图及画布共用最大 400 pt 宽的固定比例区域，单图面板基准高 196 pt，多张按原顺序纵向排列及 8 pt 间距，整组等比例适配窄窗口。正面按内容收紧，背面长解析可滚动。控件保持原有 44 pt 高及现有主题色。
- **验收。** 检查正面题干在上、题图在下、图内 A 至 D 完整、无冗余四行。用长题干、多图和无图题检查窄分屏完整性，翻面核对答案和解析，以及普通模式全屏看图。

## 在闪卡上涂鸦

- **入口与交互。** 底部中间「编辑」改为「涂鸦」。从背面点此按钮会回到正面开始涂鸦。正面右上角呈现共享原生画笔、橡皮、撤销、清空、笔设置及手指工具。透明画布覆盖题图区域，进入涂鸦时停用点按翻面和题图放大，两种状态保留相同的题图坐标。中间文案变为「完成涂鸦」，与工具条的退出共用提交逻辑。
- **数据与边界。** 复用 PencilKit 画布与错题涂鸦会话。闪卡和详情布局坐标不同，闪卡按错题和题图序列另存笔迹到 `flashcardDoodleDrawings`，原详情笔迹独立。笔迹随题图整体缩放，换题、换图不会错位或串到其他卡。保存时校对记录最新版本，保留并发更新的其他字段。无图卡关闭涂鸦入口。切卡先保存再前进，保存失败留在原卡并显示错误，正常退出后显示已存笔迹。离开闪卡视图时提交当前画布。
- **验收。** 实际画线后完成，换卡再返回，核对笔迹位置。测试 Pencil、手指模式、撤销、清空再保存、保存失败后重试，以及涂鸦时轻点不翻面。验证横竖或分屏缩放后笔迹对齐以及详情页涂鸦可正常打开。
