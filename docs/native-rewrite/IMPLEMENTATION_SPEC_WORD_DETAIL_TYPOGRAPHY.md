# 词语详情阅读排版

## 行测词语库与首页词语复习 → 词语详情

- 原型。以用户确认的[原界面微调图](C:/Users/bao/.codex/visualizations/2026/10/01/01a0f53f-c257-7bc0-b5cf-12b3bcf9c245/word-detail-typography/word-detail-current-layout.png)为参照。正文目前沿用原富文本格式，表格的常规与加粗文字均为 12 pt，窄窗中的固定表格宽度可能进一步降低可读性。
- 正文。保持原字体、字号、字重、已有强调、颜色及链接。原生正文基准 16 pt，现有富文本一级、二级标题仍沿用 21、18 pt。只调整显示用的段落样式，正文行间距至少 3 pt、段后至少 4 pt，章节标题段前至少 8 pt、段后至少 5 pt。保留原本更大的间距及空行。
- 表格。表内常规、表头半粗和局部加粗统一由 12 调到 13 pt，单元格换行增 2 pt 行距。原有横向内缩 7 pt，上下各由 7 调到 8 pt，最小行高由 34 调到 36 pt，文字多时按最大单元格实际高度增长。沿用淡灰横线、白底、既有列宽分配和顶端左对齐。内容区小于 440 pt 时用实际可用宽度重新测量并换行，较宽时沿用原 440 pt 宽度。
- 实现落点。`WordLibraryRecordDetailView` 选择专用阅读排版，样式落在 `NativeRichTextDisplay` 段落显示和 `NativeTableAttachment` 的同一套测量、绘制逻辑。正文用显示副本处理，HTML、表格数据、字重标记、编辑页和共享表格样式的其他使用场景沿用原规则。详情顶部导航、标题、关联错题、复习评价行按原样展示。
- 边界。兼容普通释义、辨析、原生表格及安全预览解析。结构简单的旧 HTML 表格在显示时沿用原生表格排版，带有自定义样式、链接或复杂单元格的 HTML 表格沿用原渲染。已有粗体、列表、图片等格式继续显示。窗口伸缩时仅在可用表格宽度变化后重新测量。保留原有长正文滚动方式。
- 验收。分别从词语库和词语复习打开截图中的辨析词条。检查表头、正文和粗体均为 13 pt，旧正文及标题大小一致，正文和表格多行间距更松，第二节与第一张表有清楚分隔。在 iPad 全屏和窄分屏检查三列长文本换行且末行未裁切，滑到底可见完整内容和原评价按钮。对照只有普通文本的词语、原有加粗和无表格内容，确认编辑、保存、错题笔记和迁移页沿用原呈现。
