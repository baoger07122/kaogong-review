# 考点按当前分组浏览与新增

## 入口与现状

新增／编辑错题、详情中的「选择考点」共用按题型、数量关系或普通模块的选择器。旧版进入自建分组后把未分组考点追加在列表下方，搜索会跨分组。点击「新增」时另开分组弹窗。标签管理的考点页已经按分组浏览，默认仍选第一个自建分组。

## 实现

- 复用组别胶囊，在左端固定显示「通用」，随后按原顺序显示自建分组。初次打开和切换科目、模块或题型后选中「通用」。保留原 11 pt 中等字重、28 pt 高、6 pt 间距和蓝色选中样式，窄窗口保持横向滚动。
- 候选区和搜索只显示当前分组。当前题已选的标签继续放在输入框里，切组时保留已选项。空分组和搜索无匹配给出提示。当前来源已有同名考点时沿用原防重复逻辑，可切换对应分组选择。
- 点击输入框旁「新增」或键盘提交，直接保存到当前分组。保存成功后清空搜索并按原规则选中；分组已变或保存失败时保留输入并显示原因。点「确定」确认本题关联，错题保存流程沿用原入口。
- 「通用」使用现有无分组 ID 的标签集合。打开后旧的未分组考点直接出现在「通用」，原有自建分组及错题引用原样读取。老数据若恰有同名自建分组，在界面显示为「通用（自建）」，仍使用它原本的 ID。标签管理、移动分组入口和排序使用同一分组含义，删除自建分组后其中的考点进入「通用」。
- 本次规则适用于考点选择和标签管理的考点页。错因标签及题库列表的筛选弹窗沿用各自现行交互。

## 验收

1. 打开图推「平面图形」的考点选择，默认「通用」并列出旧未分组考点。选「均有封闭外框」，候选区仅显示该组成员。
2. 在该组输入「直角数」点「新增」，核对直接出现且自动选中。切到「通用」新增另一个考点，确认只在「通用」候选区显示，已选标签仍在输入框。
3. 在当前分组搜索另一组的标签，验证不会出现跨分组结果及重复新增。切换题型后核对默认组，保留已选标签。数量关系与普通模块也按同样路径核对。
4. 检查空目录、窄分屏、已有同名自建组、移动到「通用」、排序和删除自建分组后的结果。关闭再重进核对持久化。
