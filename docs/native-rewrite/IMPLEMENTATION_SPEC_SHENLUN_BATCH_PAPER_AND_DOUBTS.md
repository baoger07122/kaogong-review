# 申论疑惑优先与整卷录入

## 1. 练习详情的疑惑区

- 单题与套卷的练习详情。此前「已有疑惑」在答题纸下方默认折叠。将「疑惑」卡放在作答区顶部，15 pt 中字重标题、13 pt 标签及操作、14 pt 正文，白底圆角 12 pt、内边距 14 pt。直接显示当前题的疑惑原文及已有材料页码，空态显示「还没有记录疑惑」。标题右侧「记疑惑」使用应用蓝及至少 44 pt 点击区。疑惑和答题纸使用同一列的滚动区，切题后回到该列顶部，长列表可继续滚动。
- 答题纸在疑惑后，沿用红格、字数上限和键入焦点。打开键入时定位到编辑器，底部「完成作答」按已有规则提交。完成后的复盘优先显示「逐条答疑」。记录疑惑附当前题和材料页锚点，保存失败保留输入；记录时同时保全当前已确认的答案草稿。
- 验收时打开空题、已有疑惑的题和已完成题，检查优先顺序。记录两条带不同材料页的疑惑、换题，确认只显示各题自己的记录。点红格键入，切题、完成、返回，核对光标和草稿。在窄分屏复验可达性。

## 2. 新建套卷一次录入整卷

- 入口为申论 → 套卷练习 → 新建套卷。原表单只维护一份题目草稿，保存写入首题，因此新建套卷看起来像录入单题。改为先填套卷名称，再管理共享材料和多个题目。宽窗 900 pt 起左右并排，左侧材料，右侧题目；窄窗在卷名下使用「给定材料／题目」分段，两个分段共享同一套卷草稿。在“题目”卡片用「第 1 题」等选择条逐题切换。支持添加、移除尚未保存的题目。每题复用题型、来源、原题号、分值、字数、题干、作答要求和可选参考答案字段，继续支持从套卷详情添加或编辑单题。
- 材料支持新增文字材料和导入原有 PDF／图片，保留按份整理与撤销。整卷可点「批量粘贴材料」或「批量粘贴题目」，将全文粘贴到对应面板，预览后追加。默认识别行首编号标题（如「材料 1」「给定资料 2」「第 3 题」及常见中文大写题号），允许用单独一行三个短横线分隔。题目的行首「要求」可提取为作答要求；其余正文和换行保留。无法识别为多条时保留为一条，预览展示拆出的项目和数量供确认。空文本无提交，开错模式可取消。
- 每题单独选择关联材料，材料 ID 可以复用到多题。「关联全部」和「本题无需材料」只作用于当前题。添加、删除、换题通过稳定题 ID 和材料 ID 操作，切换输入不会复用另一题的绑定。保存前检查卷名、至少一题、每题题干及分值、字数、文字材料正文和 PDF 页码。定位到首个无效题并保留全部表单。整卷、按录入顺序排列的题目、材料及附件一起写入独立上下文的同一 SwiftData 事务。沿用现有记录结构、题目读档、涂鸦和答疑归属。验证失败或取消保留旧卷，暂存新增内容不单独落盘。新卷保存成功时进入第一题。
- 验收时批量录入至少三份材料和三道题，核对拆分预览、题号顺序、各题独立字数/题型/材料关联。返回题 1 修改后切题，再保存重开，验证题目和材料完整、作答及疑惑独立。覆盖普通粘贴、PDF 页码错误、空题干、删掉草稿题、取消及切换已存在卷的题。

## 3. 申论首页与录入表单的行测样式

- 左侧导航沿用行测侧栏的行组件、选中底色、字重及图标尺寸，保留申论「单题练习／套卷练习」和各自记录数。宽度阈值 760 pt，极窄窗口收窄侧栏。
- 单题和套卷复用白色 16 pt 圆角、0.8 pt 行测描边、14 pt 边距的表单区块，图标和 13 pt 中字重标题同排，字段输入仍用 15 pt。用系统导航的单个返回入口与右侧保存操作。窄窗使用现有单列输入方式，检查分屏窗口控件避让。
