- 发布基线：`codex/ios-native-rewrite` 上的 11.24.3 / Build 165，提交 `476463d952abaa7101e95b4ab10cee4025288dc4`。
- 实现来源：`723c853ba208831534ad091b58a9f948a2e0865a`，是上述基线的直接子提交。本轮只整合这一批已完成的申论阅读与复盘布局，不纳入后续全流程原型或其他工作树内容。
- 详细实现规格：[申论材料缩放、格子纸与复盘布局](IMPLEMENTATION_SPEC_SHENLUN_READER_AND_REVIEW_LAYOUT.md)。

## 本轮范围

1. 详情宽窗口左右等宽；材料、作答要求、PDF 和图片首次按材料栏宽铺开，支持单指滚动与双指捏合；操作时暂显倍率，可选 50–300% 或适应宽度。材料、翻页和笔迹共用同一纸面坐标。
2. 格子纸保留原字号与行距；行内编号合并，段首编号和句间编号合并，小数不合并；复盘仅展示题目上限和实际使用格子，不显示未使用备用格。
3. 交卷后默认「对照答案」；成绩位于答案页顶部；疑惑和心得在独立「本次复盘」页保存。成绩保存与复盘保存各自更新同一作答记录且不覆盖另一页尚未提交的草稿。

## 验收范围

- 每次推送仍运行仓库现有 `ShenlunWorkspaceBehavior` 领域行为检查。
- 仅在发布工作流为申论改动挑选的 iPad 模拟器测试范围内，运行申论纸面与答案/复盘交互验证；不启用整套速算、题库和导航模拟器组。
- 交互验收：发布流程运行 `ShenlunReaderInteractionUITests` 的纸面捏合/倍率/涂鸦画布坐标用例，以及完成作答后默认答案页、成绩位置、格子纸/普通切换、心得与成绩双向独立保存用例。进入单题，捏合纸面并通过倍率菜单选择比例；打开涂鸦，在缩放纸面上画线，核对画布与纸面坐标对齐；完成答案后默认落在「对照答案」，分别保存成绩和心得并往返切换。
- 模拟器自动化通过不等同于 iPad 实机验收。实际 Pencil 书写、PDF/图片材料缩放、分屏和旋转仍单独记录为实机待验。
- 发布触发：向 `codex/ios-native-rewrite` 推送一次触发 `ios-native-unsigned.yml`，不得对同一提交手动重复派发。只有 Release IPA 资产可下载后才报告发布完成。
