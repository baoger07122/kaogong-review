# Native 11.24.1 发布批次规格索引

目标版本：11.24.1 / Build 163（2026-11-24，Asia/Shanghai）。核对时最新 Release 为 11.23.1 / Build 162；`native-v11.24.1` 标签未占用。

## 本批执行范围

本轮只包含以下两份已确认的申论实现规格：

1. [申论答题纸输入与返回热修](SHENLUN_ANSWER_INPUT_AND_NAVIGATION_HOTFIX_SPEC.md)：红格和「键入」进入同一原生多行编辑器并获取焦点，已确认答案同步回答题纸；练习详情改用系统导航栏，避免自绘返回与 iPad 窗口控件重叠。iPad 中文输入、焦点和分屏交互按规格待实机验收。
2. [申论文字材料粘贴排版整理](SHENLUN_MATERIAL_TEXT_FORMATTING_SPEC.md)：文字材料编辑框下方提供「整理排版／撤销整理」，合并 PDF 粘贴行断、保留可识别段落、标题和编号；仅作用于当前文字材料，不处理题干、答案、PDF 或图片。
