# 错题思维误区并入错因说明

## 错题卡片、详情、新增和编辑

- 入口为行测错题卡片、错题详情与新增或编辑错题、详情里的错因快捷编辑。当前「思维误区」「误区」「陷阱」独立展示或录入，部分模块隐藏该行。
- 移除独立行。编辑页沿用现有 `LibraryMultilinePlainTextInput` 的「错因说明」行及其字体、颜色、间距和窄窗口多行布局。卡片和详情沿用现有「错因」行及其多行样式，提醒、错因标签和考点的位置及组件保持原样。
- 读取错题、索引与旧草稿时，先显示已有错因说明，再按行附加 `pitfall`、`misconception`、`thinkingTrap` 和历史中心理解误区，跳过空行及已出现的迁移行。保留中文标点，不按逗号拆分。数量关系沿用已有的旧弱项兼容和明确保存规则。
- 已存题目即刻按合并结果显示和搜索。编辑、快捷编辑保存时同一笔事务写入合并后的说明并清除旧字段，失败沿用原回滚。取消不写入。导入的旧格式和恢复的旧草稿走相同兼容规则。题库的历史导入字段保留可读。
- 验收：用只填误区、同时填两个字段、重复内容、多行含逗号、资料分析、逻辑填空和数量关系各验证已有题。打开卡片、详情和编辑确认内容完整。快捷编辑删除一条并保存，重进确认不会复现。恢复旧草稿后检查内容并正常保存。

## 标签管理词库

- 「更多」中的「思维误区」入口移除。对应模块的历史词条并入现有「错因说明词库」，保留原顺序，已存在的词条不重复加入。数量关系跨题型的旧「数量关系-弱项」词条放入词库的「通用」，沿用现有菜单样式。
- 用当前词库的增删改保存路径写入合并结果并记录已合并的旧词库版本。以后重进不会重新加回用户删掉的词条，旧备份可继续读取。
- 验收：为两个模块准备各自旧词条，其中一个与现有词条重合。进入错因说明词库检查分组和去重，删除一个迁移词条后重进，确认删除生效。

## 词语与笔记表格横线

- 入口为错题笔记、词语详情等采用横线样式的富文本表格，在读态和文中编辑态共用 `NativeTableAttachment`。现有行间分割线为 `#E5E5EA`、1 物理像素，浅底下对比偏低。
- 行间横线采用 `#96969C`、1 pt，从首列左缘贯穿末列右缘。保留现有字体、字重、列宽、行高、单元格内距和换行方式。只绘制相邻行之间的分隔线。单行表格沿用原样，窄窗口沿用原列宽及换行规则。
- 验收：打开已有两行及以上表格，分别在错题笔记阅读、编辑和词语详情中对比横线清晰度，检查标题行与正文行分隔以及窄窗文字换行。
