# 考点筛选、分组与原位排序实现规格

本轮以已发布的 `native-v11.13.1`（build 145，`ad4c83e4fbfb17da00896e06d41d7b280062d8f2`）为交互基线。执行时从远端当前开发分支核对该基线及后续交付记录，保留其他任务的工作区变更。本轮涉及学习库错题的考点筛选、新增和编辑错题的考点选择，以及首页考点管理。错题详情内复用同一考点选择器的入口也应一致。

## 1. 用考点选择器筛选错题

**入口和现状**　学习库 → 错题 → 右上角菜单 → 标签筛选。当前筛选入口打开单选下拉菜单，候选项混有「不会做」「不确定题」等记录类别。

**目标**　点现有筛选入口打开居中「筛选考点」弹窗。候选项为当前范围内的考点，可搜索、多选及跨分组保留选择。选中态和录入考点一致。显示「已选 N 项」，有选中项时可点「清空」。点「确定」一次应用，点 × 或取消关闭时保留打开前的筛选。零项确定时恢复当前范围内的全部记录。筛选弹窗的搜索提示为「搜索考点」。

**实现**　拆出同一套考点弹窗容器、搜索框、分组栏、标签和页脚，录入用 `select` 行为，筛选用 `filter` 行为。筛选模式提供搜索和选择，录入模式另外提供新增、排序和跨题型选择。保留筛选入口的位置和显示控件开关，入口有已应用选项时显示「考点 · N」。筛选状态用独立的考点标识集合接入 `LibraryView` 的分区状态，保留真题与模拟题各自的选择。应用条件为命中任一所选考点，同时满足当前来源、科目、模块、题型、搜索、掌握状态等现有条件。切到另一科目、模块或题型时，保留在新范围仍可用的选择，移除范围外的选择。关闭考点筛选控件或执行现有「清除筛选」时清除已应用的考点集合。

**身份和索引**　在 `LibraryView.swift` 替换错题的旧 `selectedTag` 路径，候选项按考点库和记录中的实际考点引用生成。优先使用 `LibraryKnowledgePointReference` 的完整身份；全科目视图中同名异类考点分别列出并标明归属。兼容现有仅存考点名的记录，有明确归属时按该范围匹配，存在同名歧义时保留为旧考点引用。若 `StoredRecord.makeIndexPayload` 尚未包含 `knowledgePointRefs`，补入错题轻量索引并兼容已安装版本的旧索引。与 `LibrarySnapshotCache` 的显示列表和详情左右切换序列共用同一结果，避免在滚动或绘制每张卡片时读取完整正文、富文本或图片。

**验收**　在同一列表中准备分别关联 A、B、A 和 B、无考点的四道题。多选 A、B，确定后前三道可见。取消弹窗时结果保持，清空并确定后四道均可见。切换来源分别验证状态。准备两个不同题型的同名考点，选择其中一个时验证实际匹配；在筛选结果中进入详情并横滑，核对范围一致。

## 2. 两个弹窗共用尺寸和标签样式

**入口和现状**　新增或编辑错题 → 考点使用居中弹窗。此前预览的筛选框和标签比录入框小，用户以现有「选择考点」的截图为尺寸基准。

**目标与实现**　在 `LibrarySelectionDialogs.swift` 的考点分支共用 `NativeEditorDialog`、`NativeModalContainer` 和现有标签视觉参数。新建弹窗标题为「选择考点」，筛选弹窗标题为「筛选考点」。两个模式以同一窗口宽高、同一字体设置为比较条件。

| 元素 | 实现规格 |
| --- | --- |
| 外框 | 居中。标准 iPad 窗口宽 420 pt、高 468 pt，内边距 20 pt。宽度取 420 pt 和可用宽度减 48 pt 的较小值，高度按可见安全区域收缩。容器背景、圆角和遮罩复用现有考点弹窗。内容少时维持同尺寸。 |
| 标题、关闭 | 标题左对齐，系统字体 17 pt、semibold。关闭位于右侧，30 × 30 pt，11 pt 粗体 ×，沿用现有圆形关闭样式。 |
| 上部控件 | 搜索高 44 pt。录入模式有当前题型、跨题型入口和「新增」，筛选模式使用通宽搜索。分组栏高 28 pt、字号 11 pt medium、横向内边距 10 pt，标签间距 6 pt，放不下时单行横向滚动。 |
| 考点标签 | 复用系统字体 12 pt regular、横向内边距 10 pt、纵向内边距 8 pt、圆角 6 pt、横纵间距均 6 pt。白底弹窗内，未选标签沿用原浅灰填充和主文字色，已选沿用原浅蓝填充和蓝色文字。两模式复用同一选中标记规则和尺寸。同名标签在同一宽度与状态下有相同尺寸。标签按内容宽度从左往右换行，单枚超长标签可在自身内折行。 |
| 标签区和页脚 | 标签区独立滚动，顶部控件和页脚固定。页脚为已选信息行 18 pt、间隔 8 pt、居中「确定」210 × 44 pt，窄窗口受内容宽度限制；无信息时留同等空间。按钮复用 `NativePrimaryButtonStyle`。键盘和横屏缩小可用高度时，优先缩减标签区，确定和关闭仍可操作。 |

## 3. 在选择器内长按原位拖动

**入口和现状**　新增、编辑和详情内的考点选择弹窗中，「管理顺序」会打开另一层排序界面。

**目标与实现**　去掉考点选择弹窗内的「管理顺序」按钮。轻点仍切换选择。长按后在当前标签流直接拖动，其他标签即时让位，标签可跨行移动，松手后写入顺序。用 UIKit `UICollectionView` 的交互移动 API，使用系统长按手势或 `beginInteractiveMovementForItem(at:)` / `updateInteractiveMovementTargetPosition(_:)` / `endInteractiveMovement()` / `cancelInteractiveMovement()`。布局保持第 2 节标签流规格，手势识别成功后取消该次轻点。需要垂直移动时优先保证标签区可滚动。现有考点管理页继续负责重命名、删除及分组管理。[Apple 交互移动文档](https://developer.apple.com/documentation/uikit/uicollectionview/begininteractivemovementforitem(at:))

**保存边界**　拖动只影响当前所浏览题型和分组；保留完整序列中其他分组标签的相对顺序。跨题型面板进入另一个题型后可在其内部排序。筛选模式、搜索结果和未明确归属的旧引用不接受拖动。只在实际移动完成后调用原考点库的排序写入一次，取消、原位释放或写入失败恢复原顺序，失败时在弹窗显示「排序未保存」。拖动期间保持选择集合和草稿不变，排序写入成功后独立生效。

**验收**　选中一个考点后把另一个考点跨行移动，核对原选中项和题目草稿。关闭重开选择器并进入考点管理检查顺序。验证取消拖动、选中过滤、分组和跨题型的排序边界。

## 4. 考点分组管理

**入口和现状**　首页 → 考点管理。科目、模块、题型已决定考点库的作用范围，范围内当前为单一标签列表。

**目标**　在当前考点库中点击「新增分组」，输入名称后保存。可通过分组编辑改名或删除，可在考点行菜单中点击「移动到分组」，选择该考点所属的一个分组或「未分组」。录入和筛选弹窗的横向分组栏仅显示用户实际建立的分组，按建立顺序排列，默认展示首组；切换时保留勾选。没有自建分组时直接展示标签列表。有自建分组和剩余未分组标签时，在当前组标签下设「未分组」小节，12 pt medium 次级文字，使用同一套标签间距；分组栏没有「全部」或「未分组」胶囊。分组为空时在组内显示「暂无考点」。录入弹窗有活动分组时，从该分组内新增的考点直接归入该组。输入搜索文字时，搜索当前题型内所有分组与未分组标签。

**实现**　分组元数据使用持久化标识，作用域为既有科目／模块／题型，成员采用该范围中的考点完整身份。旧数据读取为未分组。分组名去除首尾空白，同一作用域内拒绝空名、重名并就地提示。分组移除时成员回到未分组，保留标签、关联题目和现有手动顺序。考点重命名、删除或从旧目录归入题型时同步更新相关分组索引，避免残留孤立引用。使用现有存储及事务边界，保存失败回退相关变更并保留编辑输入。

**验收**　在「排列组合／概率」自建「排列」「组合」并把两个标签移入不同组。两种弹窗应显示相同分组，切换后可看到各自标签并保留跨组选择。另一题型无此分组。删除「排列」后，该组原考点及关联题目仍可用，标签出现在未分组小节。用没有分组的旧库打开，直接显示原有列表。

## 5. 言语理解的三级考点和旧考点归属

**入口和现状**　言语理解 → 模块 → 题型（例如「逻辑填空 → 命题研究」）。在 11.13.1，`LibrarySelectionDialogs.swift` 同时读当前题型考点和模块级 `legacyNames`，并在题型选择面板渲染后者；`KnowledgePointManagerView.swift` 的题型页只读该题型库。两个入口读取范围不同，能解释录屏中有些考点可选却不在当前题型管理页。具体旧考点来源以该标签的保存记录为准。

**目标**　默认仅列当前第三级题型的考点。点「＋ 跨题型选择」浏览同一言语模块下的其他第三级题型，保留跨题型已选项，返回题目后其模块和题型维持原值。新考点加入明确的当前浏览题型。模块尚未设置题型时使用该模块的「旧考点」目录，明确标示当前范围。已经关联的模块级旧考点仍显示在题目的已选项、卡片及详情，可在选择器取消关联；已设置题型的题目选择器中，这些旧考点只显示为已有选择。首页考点管理在模块下提供「旧考点」，显示旧目录及能明确识别为该模块的旧引用。用户可逐个点「归入题型」，选择本模块的现有题型。

**实现**　让考点管理和选择器共用 `VerbalReasoningKnowledgePointRepository` 的题型查询。`TagLibraryRepository` 的模块级旧标签保留单独来源。归入题型时基于 `(module, typeID, name)` 查找已有目的考点，复用同题型同名目标，并原位更新所有确实引用旧身份的题目及轻量索引。对仅存名字的旧记录，只在来源模块和旧身份可以无歧义判定时随迁。含歧义的记录继续显示原有内容和旧归属，等待明确归类。整个归入操作在同一事务内更新考点库、分组元数据、关联引用及索引，按完整身份去重，保留其他选项的顺序及其他题型同名项。保存失败时保留原内容和归属，显示「归入失败，请重试」。

**验收**　用同一模块两个题型、同名但不同题型的考点、一个只在旧目录的考点、一条只有旧名称且归属明确的历史记录复现。核对两入口的当前题型列表一致，跨题型选中后原题型保留，旧题原有关联可见。手动归入旧考点后，目标库和旧题同步更新，其他题型同名项不受影响；含歧义旧记录仍可读取原内容。
