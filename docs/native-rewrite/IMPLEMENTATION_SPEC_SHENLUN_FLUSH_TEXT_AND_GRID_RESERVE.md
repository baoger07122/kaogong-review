# 申论正文顶格和答题纸备用格

- 入口为申论单题与套卷内单题的录入、材料阅读、作答和对照答案。纸面正文当前有自动首行缩进，粘贴文字也可能带行首空格。移除自动缩进，段首与正文左边界对齐。新粘贴到正文的行首横向空白去掉，现有正文和键入时手动输入的空格保留。粘贴到行中保留用于分隔文字的空格。材料现有段落识别和一键撤销继续可用。
- 红格数量在正数字数上限之后增加 100。比如题目上限为 400 时显示 500 格。25 列、每张 600 格，以及格子的尺寸、字形、红线沿用原组件。备用格用浅蓝底标识，表头显示已用格数与总格数，旁注题目上限与备用 100 格；超出备用区才出现格数提示，输入原文始终保留。未设题目上限沿用普通文字区域。
- 段末（显式换行或文本结束）及否则会落在下一视觉行开头的中文句号「。」和前一可见字符共用一格，字号略小并放在格内右下角。句中有空间时标点照常占格；用户明确另起一行敲句号时保留该换行。同一输入段行首（允许手动缩进）的「一、」「二、」和 `1.`、`2.` 等把编号及其紧随的标点作为整体放在一个格子。支持全角数字和点号，小数仍逐字符占格。格子的投影与计数变化只用于答题纸，原文保留字符和段落。
- 交卷后在「对照答案 → 我的作答」增加原生分段控件「格子纸／普通」，默认格子纸并记住最近一次选择。格子纸复用答题纸投影、分页、备用格与溢出提示，仅供查看。普通模式显示可选择的原文。未设字数上限时按实际占位铺满最后一行；补录没有原文的记录只显示空态。选择历史作答后从格子纸第一页开始。
- 验收时粘贴带空格的多段材料和作答，核对顶格及手动缩进，切到对照答案检查原文。上限 400 的题输入 401、500、501 格，核对备用区与超出提示。检查段末句号、恰逢第 25 格的句号、段首编号、10. 和 1.5，以及上限恰为 600 时备用格分页。横屏和窄分屏均确认格内合排可辨识。
