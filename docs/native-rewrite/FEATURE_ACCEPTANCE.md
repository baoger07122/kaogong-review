# 原生重写功能与交互验收矩阵

> 本文以 Web `v8.25.3` 为功能基线。目标是保留用户能力与数据结果，不要求复制 Web 的布局 Bug、Safari 工具栏问题或 CSS 实现细节。

## 全局壳层

- [ ] iPad 横屏、分屏和旋转时布局稳定。
- [ ] 主导航包含：首页、学习库、复习、套卷、设置。
- [ ] 原生导航返回路径与来源上下文一致，不依赖浏览器历史。
- [ ] 原生 Tab、NavigationStack、Sheet、Alert、ContextMenu 和侧滑操作风格统一。
- [ ] 点击、保存、成功、警告使用统一原生震动；速算音效独立保留。
- [ ] 离线可启动、可查看和编辑本地数据。
- [ ] 所有危险操作有一致的原生确认窗口。

## 全局 UI 设计系统

- [x] 页面标题、分区标题、正文、辅助文字、标签和数字使用固定字体层级。
- [x] 主色、成功、警告、危险、文字、背景和分隔线颜色在所有页面含义一致。
- [x] 页面边距、卡片间距、圆角、图标尺寸和最小点击区域使用固定档位。
- [x] 同类卡片、按钮、输入框、选择器和列表行不因页面不同而改变基础样式。
- [x] 新增待办、新增标签、新增便签等同类操作复用同一个原生弹窗外壳。
- [x] 删除、清空等危险操作复用同一个确认窗口和危险按钮样式。
- [x] 正常、按下、选中、禁用、加载、空状态和错误状态均可清楚辨认。
- [x] 页面切换、选择器、弹窗和保存反馈使用统一动画节奏并支持减少动态效果。
- [x] UI 实验室在 iPad 横屏主要半屏宽度下不截断、不遮挡、不出现过密点击区域。
- [x] 用户在 UI 实验室中实际操作按钮、表单、弹窗和状态示例后明确回复“确定预览”。
- [x] 字体密度按 Web 稳定版核对：页面标题、分区标题、卡片标题、题干正文和辅助文字均有固定令牌。
- [x] 底部导航内容区高度、图标尺寸、文字尺寸和上下留白已在主要半屏宽度确认。
- [x] 表单属性单选和日期选择使用统一弹窗，不使用页面临时创建的横向选择器。
- [x] 新增弹窗有统一出现/消失动画，仅保留居中保存按钮；删除确认固定删除在左、取消在右。
- [x] 成功状态的颜色、图标和 Toast 已确认，不使用页面自定义绿色图标。

## 统一交互库

- [x] `INTERACTION_LIBRARY.md` 中 INT-01 至 INT-15 已逐项确认或明确安排到对应阶段。
- [x] 新交互先登记、预览、用户确认，再进入正式统一组件库。
- [x] 业务页面只复用已确认组件，不复制后局部改样式。
- [x] 富文本、涂鸦、速算、图推闪卡、思维导图、复习作答和备份冲突分别走专用交互验收。

## 首页

- [ ] 顶部搜索可搜索错题和知识点，并进入正确结果上下文。
- [ ] 首页保留五个快捷入口：待办统计、学习报告、速算练习、时政常识、考点管理。
- [ ] 今日待办：新增、编辑、完成、恢复、删除、类型筛选、折叠状态。
- [ ] 学习计时：开始、暂停、结束、跨页面持续和统计沉淀。
- [ ] 倒数日：新增、编辑、删除、剩余天数、备份和恢复。
- [ ] 便签预览：两列瀑布流、置顶、按创建时间排序、点击直达编辑。
- [ ] 五个快捷入口均有统一图标、文字、点击反馈和对应页面路由；尚未进入正式开发阶段的复杂页面至少保留已确认的入口与页面壳层。
- [ ] 学习统计入口和首页汇总数字准确。

## 学习库

- [ ] 左侧科目栏：全部、六科、点击展开/收起模块，不因第二次点击跳转到错误页面。
- [ ] 主内容横向页面选择：错题、笔记、便签；逻辑填空笔记页额外提供词语库入口。
- [ ] 科目、模块上下文在新建内容时自动带入。
- [ ] 错题列表保持 iPad 两列瀑布流、筛选、搜索、尺寸密度和卡片摘要。
- [ ] 笔记列表支持模块独立标签、筛选、排序和卡片摘要。
- [ ] 便签按模块隔离，不能与首页全局便签错误混用。
- [ ] 资料分析扁平科目规则兼容。

## 错题

- [ ] 普通错题字段：科目、模块、考点数组、错因、易错点、图片、题干、选项、正确答案、用户答案、全站正确率、复盘笔记、题目来源、掌握状态、套卷关联。
- [ ] 言语理解/逻辑填空支持多个词语辨析组，每组包含词语和关系。
- [ ] 申论使用专属字段和录入逻辑：分值、总分、来源、我的框架、参考框架、段落、偏差、错误清单、遗漏清单和吸收状态。
- [ ] 新建过程自动暂存；保存后回到来源科目/模块的错题页面。
- [ ] 详情页支持就地修改状态、正文、标签和关联项。
- [ ] 支持关联套卷、关联笔记、关联词语和涂鸦。
- [ ] 删除、复制、新建相似项和返回逻辑完整。

### 图形推理专属闪卡

- [ ] 仅“判断推理 → 图形推理”使用专属闪卡页面，其他模块不受影响。
- [ ] 正面显示题目图片/题干和选项，默认隐藏答案、规律与解析。
- [ ] 背面显示正确答案、我的答案、考点、图形规律、识别思路、错因、易错点、复盘笔记、来源、掌握状态和日期。
- [ ] 支持点击翻转、上一张、下一张、位置提示、图片缩放和减少动态效果。
- [ ] 正面可进入作答/复习，背面可进入编辑，避免翻转手势与编辑手势冲突。
- [ ] 图推新建采用图片优先录入，但继续保存通用错题字段。
- [ ] 旧图推错题无需重新录入即可生成闪卡，缺少的专属字段安全留空。
- [ ] 图推专属字段在备份 JSON 和云端传输中可往返保留。

## 笔记与标签

- [ ] 笔记字段：科目、模块、考点、模块独立标签、标题、HTML 兼容正文、关联错题、关联复习和更新时间。
- [ ] 标签按科目+模块隔离；支持新增、编辑、删除、启停和调整顺序。
- [ ] 新增标签使用原生居中弹窗，不跳转到无关页面。
- [ ] 新建笔记从标签页进入时自动选择该标签。
- [ ] 详情页支持标题和正文就地编辑、自动保存和标签修改。
- [ ] 历史 HTML、旧 Markdown 和旧块数据均可导入，转换后不能丢正文。

## 富文本编辑器（TextKit/UIKit）

- [ ] 正文、H1-H4、粗体、斜体、下划线、删除线、文字颜色和高亮。
- [ ] 有序列表、无序列表、引用、代码、分割线、待办、折叠块和提示块。
- [ ] 普通文字、空白行和列表均支持缩进/减少缩进，缩进距离符合现有使用习惯。
- [ ] 表格支持新增/删除行列、表头、对齐和删除表格。
- [ ] 图片插入、错误提示、公式、笔记链接和错题链接。
- [ ] 撤销/重做、选区保持、Markdown 粘贴即时渲染。
- [ ] 格式栏固定在原生键盘上方，不跳动、不遮挡题目或正在输入的内容。

## 便签

- [ ] 全局便签和模块便签数据范围明确且互不串联。
- [ ] 两列瀑布流顶部对齐；置顶优先，随后严格按创建时间倒序。
- [ ] 点击卡片直接编辑；侧滑删除；原生确认窗口。
- [ ] 字段包含正文、标签、颜色、置顶、科目、模块、创建时间和更新时间。
- [ ] 轻量富文本只提供粗体、缩进、有序列表和无序列表。
- [ ] 时间仅显示月日，编辑不能改变创建时间排序。

## 复习

- [ ] 优先抽取未掌握且距上次复习至少 3 天的错题；无到期题时可显示全部历史错题。
- [ ] 按科目显示题量并支持按科目或全部开始。
- [ ] 显示题干和选项，重新作答后判断正误。
- [ ] 更新 `userOption`、`reviewCount`、`lastReviewDate` 和掌握状态。
- [ ] 无选项错题支持“标记为已复习”。
- [ ] 进度、结果和完成页完整。

## 套卷

- [ ] 搜索、筛选、统计、列表、详情、新建、编辑和删除。
- [ ] 套卷日期、考试名称、总分/得分、总正确率、总用时和各科成绩。
- [ ] 套卷与错题双向关联，从套卷新增错题后正确返回。

## 词语库

- [ ] 仅在言语理解/逻辑填空的笔记上下文提供入口。
- [ ] 支持成语、实词、词语辨析及词语辨析组。
- [ ] 搜索、拼音归一化、褒贬色彩筛选、行内编辑、添加、删除和样例导入。
- [ ] 词语与错题关联；辨析组多词、释义和核心差异兼容。

## 涂鸦（PencilKit）

- [ ] Apple Pencil、手指开关和鼠标/触控板输入。
- [ ] 画笔/橡皮、黑红蓝绿、细中粗、撤销、重做和清空。
- [ ] 压感、平滑、缩放/旋转后内容不变形。
- [ ] 支持错题屏幕涂鸦、手写笔记和笔记涂鸦。
- [ ] 能读取旧 PNG/Data URL 涂鸦；新数据同时提供可编辑 PencilKit 数据和兼容预览图。

## 速算（SwiftUI）

- [ ] 基础加减乘除、特殊分母、估算、增长率和资料分析真题型。
- [ ] 训练/竞速模式，题量 10/15/20。
- [ ] 自定义题型、固定数字、随机范围、历史预设和最后选择记忆。
- [ ] 自定义数字键盘：数字、小数点、清除、退格和确认。
- [ ] 计时、正确率、速度评价、错题回看、历史和统计。
- [ ] 全局触感反馈生效且不影响原有按键音效。
- [ ] 支持速记到便签。

## 思维导图（后续）
