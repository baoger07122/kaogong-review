# 错题编辑返回与退出涂鸦的本地刷新

- 本轮发布目标版本：11.27.2 / Build 168，基于已发布的 11.27.1 / Build 167。

- 入口为错题详情、编辑错题保存返回、单栏及分栏涂鸦关闭。当前保存生成新的记录版本，详情会再次解码整条 JSON。刷新期间仍显示同一道题的旧画面，但详情容器整体禁用触控。普通涂鸦还可能异步生成兼容预览，再写一次同一个记录。
- 已准备好的编辑、涂鸦及兼容预览写入，将对应 JSON 对象交给详情解码协调器。协调器只接受记录 ID、更新时间、数据长度和完整数据全部相符的版本。最多保留最近两次写入快照。保存失败、外部版本变化和主动重试时仍走原有数据校验与解码。
- 同一道错题刷新时保留旧画面，外层滚动手势可继续使用。浮层及依赖旧题目字段的交互在新版本就绪前继续受保护。切换记录、首屏读取失败、写入冲突沿用现有保护。布局、字号、工具条与错误提示沿用现有组件。
- 索引直接由已经构造的对象生成，避免同一次保存再次解码。编辑已有题目时跳过只用于新增题目的草稿快照。涂鸦预览保持后台生成，并继续按原数据版本校验后提交。
- 验收：针对含多张图片或长笔记的错题，修改题干并保存返回，原滚动区域可继续滚动且更新出现。画完立即关闭，原画面可继续滚动，重新打开涂鸦笔迹仍在。同步改同一道记录时只接纳真正已保存的版本。断言准备好的版本可零解码复用，不同内容不能命中缓存。

## 申论录入与批注图层原型

- 参考当前打开的 `shenlun-workspace-v1/shenlun-entry-and-layers.html`。申论新建单题、套卷题目及整卷录入的参考答案区默认折叠，复用现有 13 pt 标题、12 pt 次要标签和原有表单容器。点击「预录参考答案」展开，已录入时显示「已录入」。同一表单里切换套卷题目时展开状态按题目分开。编辑已存在题目时只显示是否已录入，参考答案继续由对照答案区管理。
- 「批注图层」复用现有工具栏入口、44 pt 点击区与白色弹层。面板从上到下显示当前图层提示、可滚动的图层列表、内嵌的新建或重命名表单，以及「新建图层」「隐藏笔迹／显示笔迹」。使用原有蓝色强调、次要文本和图层缩略图。窄窗沿用系统自适应弹层。
- 输入框支持取消，校验空名和同材料重复名，失败保留输入和提示。新建前提交当前笔迹，成功后切换到新图层，重命名保留原图层 ID。关闭弹层放弃未保存的名称。隐藏笔迹沿用各图层可见性设置及现有提交边界。
- 验收：录入两道套卷题，给其中一题预录答案后切题，确认另一题默认折叠且无内容。进入已录入题目的编辑页确认仅展示状态。打开图层面板，依次试空名、有笔迹时新建、同名重命名、取消输入、隐藏再显示笔迹，并验证切换材料后名称不串到另一份材料。
