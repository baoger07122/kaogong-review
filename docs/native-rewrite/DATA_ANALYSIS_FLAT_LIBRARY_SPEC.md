# 资料分析取消题目分组

- 行测学习库原来在「资料分析」下展开「单题」「综合题」「待分类」。改为与无分组科目相同的单入口，复用现有侧栏的科目字号、颜色、计数和选中状态，无展开箭头。真题和模拟题各自按原来源显示本组全部资料分析记录，包含未设分组和旧材料分类的记录。复习页的模块概览把资料分析合为一项，点击复习该科目的全部待复习题。
- 新增或编辑资料分析题只显示「科目」和独立的「错误类型」，现有模块字段的按钮及内容省略，同行其余控件按现有 8 pt 间距靠左补位。错题详情导航标题用「资料分析」，不把旧分组写进标题。关联错题、横向预览、通用列表及复习卡片保留「资料分析」科目名。资料分析笔记省略模块按钮。设置里的资料分析错误类型打开同一张目录列表，沿用现有控件样式和排序方式。
- 原题的 `module` 载荷和索引值在编辑时各自保留。新建资料分析题或从其他科目切入资料分析时以科目保存，不写分组。错误类型的 ID、历史标签目录范围及已有关联保留。录入可选资料分析的全部错误类型，历史类型的标签仍从其旧目录范围读取。标签目录的历史归属、题库原试卷的目录和浏览方式保留独立用途。
- 原分组的录入草稿可从资料分析科目入口恢复。优先取当前科目的草稿，空闲时依次取旧分组草稿。只有科目草稿键保存同一份数据后才移走对应旧键。资料分析的「标签展示」开关按科目共享，已有两个模块的展示设置一致或只设置过其中一组时继承，冲突时沿用默认值。
- 题卡和详情继续读已有材料、配图、答案与涂鸦。资料分析有题干配图时按现有首图预览展示。旧综合题保留材料卡片的版式，未设分组的题根据实际材料或配图使用材料样式。
- 验收时用一条「单题」、一条「综合题」、一条旧材料分类和一条无分组题，分别检查学习库、模块复习概览、详情标题、关联题列表和编辑表单。编辑旧题并重开，核对索引和载荷中的原分组字段保持、已有标签及图片可见。保存新题核对分组缺省、图片和错误类型可用。核对资料分析设置可对不同历史来源的错误类型排序，并验证其他科目的分组与窄窗布局。
