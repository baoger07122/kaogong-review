# 词语复习打开编辑页卡住

## 首页 → 词语复习 → 查看释义／辨析 → 词语详情 → ⋯ → 编辑词语

- 已确认的源码差异。两处入口都使用同一 `WordLibraryRecordDetailView` 和 `LibraryRecordEditorView`。词语复习在系统菜单的按钮回调中立刻改写详情导航状态；词语库用独立任务让出主线程后再进入编辑，并阻止重复请求。
- 诊断。截图停留在放大的系统菜单，和菜单退出与页面进入相互重叠的情形一致。当前没有这次闪退的设备日志，无法确认系统异常类型或调用栈。
- 目标与实现。复习详情的「编辑词语」「迁移旧词语」走同一延后导航流程，先让系统菜单提交退出，再按同一个 `recordID` 加载现有编辑页或迁移页。一次只接受一个待执行请求，离开详情时取消尚未执行的请求。词条不存在时保留现有「词条已删除」反馈。
- 视觉和保存。复用详情的系统「⋯」菜单及现有编辑页，不在这轮改动字体、字号、间距或底部评价栏样式。保存／返回仍由原编辑页处理，回到同一词条、同一队列位置，不产生复习评价与历史。窄分屏随原布局。
- 验收。同一词条分别从词语复习和词语库打开编辑。在 iPad 分屏检查普通释义和较长的成语组辨析。检查菜单关闭后进入编辑，保存标题或正文后回到同一条，返回不保存仍可复习，点击评价才推进下一条。补查快速重复点按、打开前返回、词条被删除、旧词迁移。
