# 新增图形推理错题预填题干

**入口和现状。** 行测 → 判断推理 → 图形推理 → 新增错题 →「题目与选项」。现有新建流程已预填选项 A、B、C、D，题干字段需要手动输入。

**实现。** 在现有图推选项预填时机同时检查题干。题干为空时将「从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定规律性：」写入 `LibraryRecordDraft.title`，作为可编辑正文。沿用 `ShenlunAdaptiveTextEditor`、原有 15 pt 正文、左对齐、白底以及最低 70 pt 的自适应高度，长题干及窄窗口正常折行。保存继续以输入框最终内容写入 `question`。

**边界。** 直接打开新增图推错题时立即预填。从其他模块新建并首次切到图推时，独立检查题干和选项，保留用户已输入的内容。沿用每个新建会话预填一次的规则，用户清空后切回图推不会再次填入。已有错题和恢复草稿使用原数据，智能拆分仍可替换题干。保存失败沿用原提示并保留输入。

**验收。**

1. 直接新增图推错题，核对完整题干和 A、B、C、D。
2. 从其他模块进入新增，先输入自定义题干再切到图推，核对原题干保留、空选项照常预填。另以已有选项、空题干验证可独立预填题干。
3. 清空或改写预填题干，再切换模块并返回。核对最终值保留，保存后重新打开确认。
4. 打开其他模块的新增表单、旧图推错题和恢复的草稿，核对现有题干。

收到「发布执行」后交 Luna 构建。
