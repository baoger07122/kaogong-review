# 新增图形推理「平面图形」错题预填题干

**入口与现状。** 行测 → 判断推理 → 图形推理 → 新增错题 → 题型。上一轮预填覆盖整个图形推理模块。

**实现。** 新建会话通过当前有效的题型 ID 查找题型名，在「图形推理」且选中「平面图形」时，将「从所给的四个选项中，选择最合适的一个填入问号处，使之呈现一定规律性：」写入空的 `LibraryRecordDraft.title`。带着「平面图形」的筛选进入新增和手动选择「平面图形」都适用。题干沿用原有 15 pt 文本编辑器、70 pt 最低高度与窄窗口折行。A、B、C、D 继续按图推模块预填。

**编辑和保存。** 只有会话里自动放入且仍未编辑的句子在切到「六面体」、未分类或其他模块时清掉。再选回「平面图形」可重新预填。用户改写或主动清空后，会话将后续题干交给用户，切换时保留实际输入。已有题目和恢复的草稿继续使用原值。保存按现有题干字段写入 `question`，保存失败保留输入。

**验收。**

1. 进入图推新增，先选未分类和六面体，核对题干为空且选项仍预填。选「平面图形」后核对完整句子和可编辑状态。
2. 从「平面图形」筛选列表直接新增，核对初始值。把未修改的题干切到六面体检查清除，再切回检查预填。
3. 分别改写、清空默认题干后切换题型，核对实际值保留。新建时先手填题干再选「平面图形」也应保留自定义内容。
4. 已存题目、恢复的草稿、其他模块内的同名类型沿用原内容和录入路径。

收到「发布执行」后交 Luna 构建。
