### 可点原型

[打开 shenlun-reader-demo.html](shenlun-reader-demo.html)；解压后直接用本机浏览器打开，不需要服务或外部依赖。初始打开示例套卷：

1. 点顶部叠片，试单层眼睛、底部整体眼睛、新建、行内 `··· → 重命名`。
2. 左栏点「作答要求」，右栏点箭头或题序跳到第 2／5 题，确认题序、材料锚点和格数。
3. 点「键入」，输入一段文字或超限文本；从全窗 `··· → 编辑题目` 调整上限，再返回检查原文。浏览器存的是样例本机数据，不与正式 App 相连。

如要直接看入口，可在浏览器地址末尾追加 `?screen=library`、`?mode=paper&screen=library` 或 `?screen=settings`。PDF／图片选择、原生 Pencil、真机持久化、App 内实际 AI 等不能用浏览器模拟替代验收。本索引不提供旧原型的「材料／作答」切页样式，也不打包原始录屏、用户聊天截图或原 PDF。
