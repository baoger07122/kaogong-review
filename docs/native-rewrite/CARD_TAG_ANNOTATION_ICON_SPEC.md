# 错题卡片考点和错因图标

- 入口为行测错题卡片的顶部标签区。按[确认图的 A 方案「灯泡与批注」](prototypes/card-tag-icon-pairing-a.png)，考点使用蓝色 `lightbulb.min`，由 Light 调为 Regular。错因标签将分岔线改为折角批注页，页内有两条短横线，右下是独立圈叉。颜色用系统次要灰，0.85 pt 描边，圆端点和圆连接。
- 在 `LibraryKnowledgePointTagCloud` 共用组件实现。两枚图标的画框均为 11 × 11 pt，位于对应标签首行左侧，沿用 6 pt 间距和 4 pt 顶部对齐。窄卡片标签继续换行，只有某类标签存在时才占该行。无障碍沿用标签类别与名称。
- 验收时检查考点与错因同时打开、各自单独打开、长标签换行以及数量关系卡片的对齐。在 iPad 窄分屏检查圈叉和折角可分辨，点开详情核对标签含义。
