# 9.3.2 速算键盘布局修复

依据 2026-09-03 用户左右对照图与 src/styles/90-speed-preserved.css 的 sc-numpad--v2。

- 原因：LazyVGrid 的数字键没有明确行高，maxHeight: infinity 未得到四等分行高；右侧三按钮均分高度，确认键未跨两行。
- 使用独立 SpeedNumberPad 与可测试的 SpeedKeypadMetrics，固定四行尺寸：1/2/3、4/5/6、7/8/9、+/-/0/小数点。
- C、退格分别与第一、二行对齐；确认键覆盖第三、四行及中间间隔。左右上下边缘齐平。
- 功能列占内部宽度 22%；间隔 7pt，侧边/顶部内边距 12pt，圆角 14pt；键高从实际可用高度计算，不依赖文字固有高度。
- 键盘按窗口高度 42% 计算，常规范围 280–340pt；短窗口缩减底部留白，避免挤掉输入区。参考网页 .page 原有底部 64+20pt 留白，系统安全区不重复加在外部。
- 颜色：面板 #F8FAFC，数字键 #F3F4F6，文字 #1F2937，功能键/确认键 #4A90E2；按压分别 #BFDBFE、#3A7AC7，保留缩放反馈。
- 本次只校准键盘及其布局空间，不改变 C 清空、退格删一位、正负号、小数点和提交判题逻辑。网页源码的 C/退格行为曾反向映射，不在本次视觉修改中跟随改变。
- 发布流程增加独立 Swift 几何测试：列宽、四行齐平、确认键跨度、窄窗口与短窗口约束。仍需 iPad 真机验收视觉、点按和自动提交。
