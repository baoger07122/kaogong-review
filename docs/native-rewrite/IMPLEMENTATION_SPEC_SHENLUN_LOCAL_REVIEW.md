# 申论单题作答与离线复盘实现规格

## 范围与入口

本轮实现已确认的单题交互原型。申论首页「单题练习」的题卡、套卷内的单道题共用同一工作区。整卷轮次、整卷心得和总分为设计稿的后续阶段。本轮套卷首页继续按题统计完成与录分。

此前每题只有一份可覆盖的作答；完成后评分页仅能查看已有评分或等待服务接入，缺少手填和心得。目标为本机完整执行首次作答、交卷复盘、历史回看、续写、重做和历史补录。

## 作答与复盘

- 宽度至少 680 pt 时沿用材料与工作区左右两栏；窄窗口延用纵向材料和工作区，进入复盘或点「继续／再做」时定位到右侧功能区，定位疑惑时滚到材料。保留材料页、缩放、切题、系统返回和涂鸦行为。
- 首次打开未做题显示「第 1 次作答」「已完成 0 次」。先显示现有红格答题纸、字数、键入操作，其后显示常驻疑惑卡。沿用现有网格和字数限制，键入正文同步到网格，超出保留正文。点击红格或「键入」聚焦。未设置上限沿用普通文字输入。完成操作提交当前作答及已有疑惑，成功后打开本次复盘。
- 复盘顶部显示当前第 N 次作答、已完成次数、日期与分数。分段顺序「本次复盘」「对照答案」「作答历史」。复盘卡片按「疑惑」「本次得分」「复盘心得」显示，复用 12 pt 圆角、15 pt 标题、14–15 pt 正文、12–13 pt 次要标签、蓝色强调色和 44 pt 最小主要操作高度。分数和来源在窄窗口可独立排列，文本允许多行。复盘默认展开疑惑，可逐条输入结论、标记「已核验」，点击锚点回看原材料页。材料被移除或换版本时保留原引用提示。
- 「本次得分」保存 0 至当次满分之间、最多两位小数的数值。满分未设置时只要求非负且有限。空分显示「未评分」并可清除已录分。可选来源为「自评」「老师批改」「外部评分」。心得用多行框独立保存。提交时一并写入分数、来源、心得、疑惑结论和核验状态；离开前保存草稿，切回可恢复，写入失败保留输入并提示。
- 「对照答案」显示已选记录的作答原文及参考答案。保留录入和修改参考答案的入口。历史原文保持可回看，旧的评分分析与待核验状态继续可见。当题目评分相关内容变化时已有分数提示复核。
- 「再做一次」打开同一题的空白答题纸；有草稿时显示「继续第 N 次作答」。返回上次复盘保留草稿。仅完成才增加计数。历史按作答实际日期倒序、相同日期按编号倒序；每次编号固定。历史支持「补录一次」，必填日期、原文可空；成功后打开该次复盘。有新作答草稿时补录仍保留它，待完成的新作答编号顺延。单题列表显示已完成次数与最近一次有效评分日期。

## 持久化

- 按题持久化作答记录集合，每条作答有独立 ID，记录完成时间和固定编号。同题仅允许一份进行中草稿，保存时检查对应记录的修订号和当前草稿，完成时以一次原子写入将其转成完成记录。历史评分、复盘心得及草稿使用各自的作答 ID，保存一次不会改写其他作答。作答记录保存当次满分和可用的参考答案，疑惑锚点保存材料 ID、版本、标题及页码。
- 旧按题记录首次读取映射为一份对应状态的作答。保留正文、现有疑惑、分析、分数和可用完成时间。历史存在后优先读取新存储，保留旧原件供兼容。重复打开或重复保存不得双计数。新增集合加入备份导入导出、随所属练习删除。

## 验收步骤

1. 打开没有历史的题，点红格，在中文输入法提交一行答案，检查格内文字与计数；记一个材料疑惑后完成，复盘首屏显示该疑惑，可跳回材料。检查横屏和窄分屏。
2. 录 0 分和心得，保存。再做一次，输入后返回上次复盘，次数仍为 1。续写后完成，次数为 2，作答、评分、心得各自独立；重复完成不新增记录。
3. 填超出满分或多于两位小数的值，检查错误及输入保留。切换记录和重新进入检查未提交的复盘内容。把分数清空后再次打开，仍为未评分。
4. 补录日期较早且无原文的一次，核对顺序与次数。检查补录过程中已有答题草稿不丢失。检查旧版题目、离线保存、备份、套卷第二题均能独立复盘。
