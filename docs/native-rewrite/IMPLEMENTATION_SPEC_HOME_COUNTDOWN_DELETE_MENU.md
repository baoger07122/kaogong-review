# 首页倒数日删除入口

## 首页顶部 → 倒数日

- 现状。每张倒数日卡片在剩余天数右侧直接提供「×」，触发后立即写入删除。点击卡片正文已可打开「编辑倒数日」弹窗。
- 目标。首页卡片仅显示名称、日期和剩余天数，整张卡片可点开原编辑弹窗。弹窗右上角增加「⋯」菜单，菜单中有红色「删除倒数日」。选择后出现系统确认，确认框显示目标名称，提供「取消」和「删除」。只有确认删除才写入，保存成功后关闭编辑弹窗。新增倒数日弹窗沿用原流程。
- 版式。卡片沿用白色背景、12 pt 圆角、10 pt 水平内边距、42 pt 最小高度。名称 12 pt 半粗、日期 10 pt 次要颜色，蓝色剩余天数 18 pt 粗体右对齐。窄窗口名称按现有单行省略。编辑弹窗复用 `NativeEditorDialog`，左侧标题沿用 17 pt 半粗，右侧为关闭按钮和靠右的「⋯」。菜单图标 16 pt 半粗、主题蓝色，44 × 44 pt 点击区域。
- 实现落点。由 `HomeView` 单独持有删除确认状态，关闭编辑器时清理。系统菜单由 `NativeEditorDialog` 的可选删除入口提供，其他调用按默认行为渲染。从 `legacy.countdown.value` 按所选记录 ID 删除一项，原样保留其他记录及其字段。旧备份中缺失 ID 的倒数日沿用可辨认的临时标识。保存失败时恢复本次变更，保留编辑弹窗并提示。目标已变更或无法唯一定位时提示重新打开。
- 验收。首页卡片上无「×」，点名称、日期或右侧天数均打开编辑，新增弹窗无菜单。分别验证打开菜单后退出、进入确认后取消、确认删除三条路径。保留至少两条倒数日，核对只有确认选中的一条被移除，关闭重开后结果仍在。另核对旧备份缺 ID、窄窗口、名称较长的情况。
