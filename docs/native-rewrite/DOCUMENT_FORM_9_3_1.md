# 9.3.1 文档式错题页面与交互补充规范

用户于 2026-09-03 确认。本页补充现有统一交互库；不改变其他未确认组件。

## 已确认设计

- 详情页导航栏至「错题」标记的内容顶部内边距从 14pt 收紧为 5pt。不改变返回键位置或系统分屏控件避让。
- 题干为 13.5pt Regular，附加行间距 5pt；选项字号不联动缩小。
- 考点、错因、思维误区三行始终显示，空值仅保留名称和冒号。
- 顶部涂鸦、更多及绘图工具使用无胶囊、无圆底的线条图标；选中工具以蓝色强调。iOS 26 隐藏系统工具栏共享背景，旧系统保持兼容。
- 保持 PencilKit、像素橡皮擦及 Pencil Pro 轻捏切换，画笔调节继续从底部展示。

## 笔记原位编辑

- 点正文或空态直接编辑，不打开错题表单、不弹半屏页。
- 复用 NativeRichTextEditor 的文档模式：无外围卡片、自适应高度，键盘上方格式工具栏及 Markdown 粘贴渲染保留。
- 输入状态仅由笔记子视图持有，避免每次输入重建整道题的图片区域。
- 输入暂停 700ms 保存当前记录；完成、离开及进入后台时补保存。保存失败可重试；进入涂鸦和整题编辑前必须保存成功。
- canonical note 字段优先，显式空值不能回退显示历史 content。存在旧 content 别名时同步写入。
- 不新增独立手写笔记页面。

## 新建与编辑页面

- 白底连续文档式表单，去除上下文、题目、关联区域外围大卡片；保留必要输入背景。
- 类型前置，科目/模块紧凑并列；图片无内容时仅一行入口，位于题干之前。
- 先题干/选项/答案，再考点、错因、思维误区；输入字体 13pt。
- 考点多选最多 3 个，错因单选，均允许为空。复用统一居中编辑弹窗，候选项和已选值均用小标签呈现。
- 选择弹窗支持搜索、新增；长按可重命名/删除，删除须确认影响范围。取消选择不改当前字段；管理动作是即时操作。
- 思维误区仅为可留空的普通文本，不展示标签候选，也不自动写入标签库。不清理已有历史数据。
- 来源套卷、关联笔记、关联词语使用紧凑属性行，11pt 标签、12pt 摘要；保留 44pt 整行点击范围。候选项在统一弹窗内选择，不在表单展开。

## 验证边界与真机清单

Windows 本地检查仅覆盖源码约束，Xcode 编译由 GitHub Actions 完成。布局、Apple Pencil 和键盘行为需真机验收：

1. 空三字段仍显示；标题下面留白缩小；全屏/半屏无返回键遮挡。
2. 多行笔记点击原位编辑，粘贴 Markdown，格式工具栏跟随键盘，长文光标可见；返回重进内容一致，清空后不恢复旧内容。
3. 标签第 4 项不可新增选择；错因单选；取消/清空/搜索/新建/改名/删除结果正确。
4. 思维误区输入不产生标签库条目；内容关联取消不改变原值。
5. 进入/退出涂鸦无额外布局跳动，工具可点，画笔/像素橡皮擦及轻捏工作正常。
