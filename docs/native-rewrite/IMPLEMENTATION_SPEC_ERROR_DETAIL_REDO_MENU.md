# 移除错题详情菜单的重做入口

## 错题详情 → 右上角「⋯」

- 现有行为。右上角已有独立的「看／刷」按钮。支持刷题的错题在「⋯」里还会显示「重做模式」或「错题模式」，两个入口切换同一个题目详情状态。
- 目标行为。「⋯」依次显示「编辑错题」「删除错题」。看题和刷题由顶栏现有按钮切换。
- 实现落点。在 `LibraryRecordDetailView.questionActionsMenu` 移除重复菜单项及它独用的文案、图标和切换方法。复用现有系统菜单、44 × 44 pt 入口和导航布局，保留删除项的系统破坏性样式。窄窗口沿用系统菜单布局。保留现有详情模式状态、列表默认模式、作答结果及笔记存储规则。
- 边界。未载入、无法作答或正在涂鸦时，沿用当前控件可用性规则。删除仍需经过现有笔记收尾和删除确认。
- 验收。打开一道支持刷题的错题，展开「⋯」确认只有编辑与删除。点击顶栏「看」切到「刷」，选择并提交答案，再切回「看」。在两种模式下展开菜单确认选项相同，再检查编辑入口和删除确认可打开。返回行测列表检查默认模式入口。
