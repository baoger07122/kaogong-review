# 词语库卡片摘要

## 行测 → 言语理解 → 逻辑填空 → 词语库

- 现状。卡片把正文转成纯文本后从首行起截取，标题、章节名和重复词名会占用摘要行数。轻量索引未包含新版辨析正文 `comparisonDocument`，旧词条仅有 `content` 时也可能读不到。
- 目标。释义卡片优先显示正文中「词义」「释义」「引申义」或「含义」后的解释。没有这些字段时，若有「字面意思」「基本义」「本义」「核心侧重」等可用解释则读取它，否则取首段有内容的文字。辨析卡片优先取「共同语义」或「核心区别」等正文内容，只有对照表时显示数据行。
- 版式。沿用 `LibraryRecordCard` 的标题和摘要样式。标题 14 pt 常规字重、主文字颜色，摘要 12 pt 常规字重、次要文字颜色，均左对齐。沿用卡片间距、内边距和列数。小、中、大卡分别限制摘要最多 2、3、5 行，窄窗按现有布局换行截断。无有效正文时只显示标题。
- 实现。复用词语详情的正文选取规则和现有富文本转纯文本逻辑。常见释义沿用有 `meaning` 的索引，需辨析正文或旧释义回退时读取原记录。快照生成时计算摘要，视图直接使用。搜索仍可使用正文全文的纯文本投影。跳过「一、词义理解」、重复词名、形如「成语积累｜词名」的正文标题、表头和单独的附件占位提示。保留原有数据格式，操作只读。
- 边界。兼容 HTML、Markdown 经现有转换后的正文和旧式纯文本。兼容标签独占一行、全角及半角冒号。缺乏明确语义字段时仍展示已有解释段落，标题和占位符构成的空正文不显示摘要。
- 验收。打开截图中的「大而化之」，卡片显示「形容做事情粗疏、不够细致，处理问题笼统，缺乏深入分析。」；「按部就班」跳过重复词条标题；「不言而喻」保留原来直接录入的释义。分别检查新旧辨析、只有表格、空正文。用正文后半部分的词搜索仍可找到词条，点击卡片可查看完整原文。切换卡片尺寸并核对行数与对齐。
