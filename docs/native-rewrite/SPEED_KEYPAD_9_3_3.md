# 9.3.3 / Build 26 — 速算键盘交互对齐

基准：`src/modules/150-speed-preserved.js` 的 `_tapKeySound`、`handleKey`，以及 `src/styles/90-speed-preserved.css` 的 v2 键盘与 `scAnsPop`。

- C 删除末位；删除图标清空全部。数字输入上限 10 字符；空输入的小数点保留为 `.`。正负号、重复小数点与网页一致。
- 所有屏幕键盘按键在按下时播放同一音效。取消系统 1104 音效和额外触感，避免数字键与功能键反馈不一致。
- 音效依据网页 55Hz 正弦、70ms、14→0.0001 指数包络生成内存 WAV。最终 PCM 限幅；预热并复用四个播放器，离开练习或进入后台释放。遵循静音开关，不更改系统音量。WebAudio 和原生输出链路可能有响度差异，不能据源码宣称听感完全一致。
- 按下数字键立即变为 #BFDBFE，功能键为 #3A7AC7；亮度乘以 0.86，60ms ease-out；缩放 0.93 / 位移 1pt 使用网页的 150ms 贝塞尔曲线。
- 算式、等号和答案按内容宽度整体居中。答案使用等宽字体，输入后从 0.8 缩放/0.4 透明度在 150ms 内恢复；长答案局部横向滚动，不再随着输入缩小整个算式。极窄窗口仅根据题目宽度调整字号。
- 保留 9.3.2 的键盘尺寸、22% 功能列、四行布局与跨两行确认键。

验证：CI 执行 77 项几何断言、14 项输入用例及音频 PCM/WAV 校验，再执行 Xcode Release archive。Windows 本地执行错题编辑相关的 8 项源码约束，防止误改其他页面。

真机验收：快速连按音效、静音/声音开关、后台返回、C/清空/小数点、1～10 位答案居中与尾部可见性、长按与松开的变色动画。未在 iPad 上进行自动化截图或听感验证。
