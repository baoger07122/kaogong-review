# 9.3.5 / Build 28 — 速算即时输入反馈

- 按键使用原生 UIControl 跟踪触摸：按下立即加深并轻微下压；抬起、滑出或系统取消立即复原，不安排恢复计时器或颜色渐变。滑出后松手不输入，保留 VoiceOver 激活及减少动态效果支持。
- 保留网页版键盘尺寸、24pt medium 数字、蓝灰色配色及按下音效；C 删除一位，删除图标清空。
- 输入答案、下划线及题号取消缩放/闪动。公式随答案宽度增长整体居中，窄窗口字体仅按题目长度计算，不按输入内容缩放。
- 手动确认后同步判分并进入下一题，删除固定 220ms 等待及整行 320ms 淡入。判分提示独立显示，不阻挡新题输入；末题进入结果页。
- 保留纯白背景、未完成退出确认、结果页和原题复练逻辑。

验证：执行输入/几何/练习流程测试与源码契约检查，另由 Xcode 构建 IPA。源码检查不能代替真机触摸验证。

真机重点：首次点击、连续快速点击、按下后滑出取消、C/清空、输入增位居中、连续确认不重复计分、末题结果、退出取消及重新开始。与网页同屏对比松手后无残留高亮，公式无缩放或空白过场。
