# 页面层

页面层按路由职责拆分，代码通过 App.Pages 注册页面，不直接改变路由协议：

1. 00-home.js：复盘首页和今日待办。
2. 10-errors.js：错题本、错题详情和错题表单。
3. 20-notes.js：笔记列表、详情和编辑。
4. 30-stickies.js：便签管理。
5. 31-study-stats.js：学习统计。
6. 40-exams.js：套卷记录。
7. 50-workspace.js：科目专属复盘工作台。

页面依赖基础层、组件层和路由层公开的 App 接口。新增页面时应在 build.js
中显式加入加载顺序，避免依赖隐式的文件名排序。
